State-Space Sequence Models: S4 and Mamba

How can a compact state remember a long input sequence?

The idea

A state-space sequence model repeatedly compresses history into a vector. Inputs update it and outputs read from it. In a fixed linear model, different decay modes retain information over different timescales; slow decay can preserve influence for many steps.

S4 uses structure to make long-sequence state-space computation efficient. Mamba makes selected parameters depend on the input, enabling content-dependent retention. That changes the assumptions behind a fixed linear time-invariant convolution. Neither architecture can be understood completely through one scalar forgetting coefficient.

Read the relationship

ẋ=Ax+Bu; xₖ₊₁=Āxₖ+B̄uₖ; simple memory: xₖ₊₁=0.9xₖ+uₖ

Discrete matrices depend on a discretisation or parameterisation. x is memory state; u is the incoming signal, not the same object as x.

Work through an example

  1. Start at zero, apply u₀=1 and set all later inputs to zero.
  2. The simple memory becomes 1, 0.9, 0.81 and so on, retaining 0.9ⁿ⁻¹ at step n.
  3. Using 0.1 instead forgets quickly. Making retention input-dependent creates a different model from the fixed convolution.

When it applies

Long memory, numerical stability and useful content selection are distinct goals. A fixed-matrix eigenvalue argument does not establish all properties of a full selective network.

Check your understanding

Does a retention factor near one solve every long-range reasoning task?

No. It must still encode, select and use relevant information without harmful interference.

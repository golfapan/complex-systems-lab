What does a command actually make the robot execute?

The idea

A learned policy may output joint positions, velocities, torques or end-effector targets. The underlying controller turns these into physical motion. Hardware limits, command rate and available measurements determine whether a proposed policy interface is meaningful.

List the readable states, writable commands, units, rate, limits and reset procedure for a hypothetical arm.

Read the relationship

policy output → command interface → low-level controller → physical motion

This is a conceptual or modelling relationship. Its role is to make the task and assumptions explicit.

When it applies

A software API accepting a command does not establish accurate tracking or safe behaviour under contact.

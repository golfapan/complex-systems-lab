Evaluation, Hallucinations and Contamination

What would make a language-model answer trustworthy?

The idea

Fluency, factual accuracy, reasoning, tool execution and task completion are different evaluation dimensions. A single benchmark score cannot replace a protocol that defines the task, available evidence, scoring rule and uncertainty.

Check whether training and test data overlap, whether an automatic judge has biases, and whether performance survives changes in wording or deployment conditions. A model judging itself creates a possible circular standard rather than an independent verification. Include failure cases alongside averages.

Read the relationship

Report task + data version + sampling settings + scoring rules + sample size + uncertainty

A hallucination is not diagnosed merely by awkward wording; check whether claims and citations are supported by reliable evidence relevant to the question.

Work through an example

  1. Ask a factual question and inspect the cited source itself.
  2. Rephrase the question and test whether the same unsupported claim persists.
  3. If an automatic judge rates the answer highly, independently audit a sample rather than treating that score as proof.

When it applies

A previously untouched test becomes less independent when repeatedly used to choose models. Correlated questions also affect statistical uncertainty.

Check your understanding

Can an answer be fluent and confidently cited but still unsupported?

Yes. Verify that the source exists and actually supports the stated claim.

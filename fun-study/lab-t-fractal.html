Mandelbrot and Julia sets

How can one repeated complex-number calculation create an intricate boundary?

Run this experiment →

The idea

Iterate a complex number using z²+c and classify its long-term behaviour. The Mandelbrot view varies c while starting at zero; a Julia view fixes c and varies the initial z. The same recurrence therefore produces two different questions about initial conditions and parameters.

Squaring changes both magnitude and angle. Fine structure arises through repeated nonlinear updates, not through forces between visible points.

Read the relationship

zₙ₊₁=zₙ²+c Mandelbrot: z₀=0; Julia: c fixed.

z and c are complex numbers. A visible escape-time image uses a finite iteration budget, not an exact decision at every pixel.

Try this

  1. Compare a broad Mandelbrot view with a nearby Julia set. Increase the iteration budget near the boundary and see which classifications change.

When it applies

Floating-point arithmetic and finite iteration depth limit detail. A dark pixel means no escape was observed within the budget, not a rigorous membership proof.

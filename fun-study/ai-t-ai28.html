A Complete Transformer Block

What does a Transformer contain besides attention?

The idea

A Transformer block combines attention with projections, a tokenwise feed-forward network, residual paths and normalisation. Position mechanisms supply order information. Attention mixes information between positions; the feed-forward part transforms features within each position using shared parameters.

Many architectural variants change norm placement, activation, positional representation or attention details. Start with one clearly defined block and trace every tensor through it. A residual addition only makes sense when the two branches have compatible shapes.

Read the relationship

Pre-norm sketch: U=X+MHA(LN(X)); Y=U+FFN(LN(U))

MHA is multi-head attention, LN layer normalisation and FFN a feed-forward subnetwork. The sketch omits dropout and implementation-specific details.

Work through an example

  1. An input with shape B×T×d typically keeps that shape through a residual block.
  2. Each head uses its own learned query, key and value projections of the input representation, then attends to the permitted sequence positions.
  3. They do not normally partition the sequence into disconnected stretches that can never communicate.

When it applies

A block diagram is not a complete model specification. Masks, projections, parameter sharing and position conventions must be stated to reproduce the computation.

Check your understanding

Why does an FFN applied at every token still share parameters?

The same feature transformation is reused at each position; activations differ because their inputs differ.

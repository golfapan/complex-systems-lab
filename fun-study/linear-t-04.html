Rank, Nullspaces and the Four Fundamental Subspaces

Which inputs are invisible, and which outputs are possible?

The idea

The column space contains all outputs Ax can produce. The nullspace contains input changes that produce no output change at all. Rank counts independent output directions, distinguishing the number of written equations from the amount of independent information they supply.

The row space and left nullspace complete the picture. In input space, the row space is orthogonal to the nullspace; in output space, the column space is orthogonal to the left nullspace. A consistent system's solutions form one particular solution plus every invisible direction, explaining why exact solutions can fail to be unique.

Read the relationship

rank(A)+dim N(A)=n Ax=b consistent ⇒ x=xp+z, z∈N(A) C(A) perpendicular to N(Aᵀ)

n is the number of columns. C(A) lives in output space; N(A) lives in input space, so they need not even have the same ambient dimension.

Work through an example

  1. For A=[[1,2],[2,4]], the second column doubles the first, so rank(A)=1.
  2. With b=(3,6), every x=(3,0)+t(−2,1) is a solution.
  3. With b=(3,7), no solution exists because the second output must always be twice the first.

When it applies

Equal row and column ranks do not mean row and column spaces are the same set. Near-dependence in measured data also requires a numerical rank tolerance.

Check your understanding

Can two equations in two unknowns have infinitely many solutions?

Yes. If the constraints are dependent and consistent, a nontrivial nullspace supplies infinitely many solutions.

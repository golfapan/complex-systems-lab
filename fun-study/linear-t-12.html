Singular Values and the Pseudoinverse

How do we separate a matrix's input directions, output directions and stretch factors?

The idea

The singular value decomposition works for rectangular as well as square matrices. It chooses orthonormal directions separately in input and output space, then connects them through nonnegative stretch factors. This reveals rank, inaccessible outputs and directions in which small data errors can be amplified.

The pseudoinverse reverses each nonzero singular stretch while leaving missing directions uncreated. It selects the minimum-norm vector among all least-squares solutions. Extremely small singular values are dangerous to invert: a mathematically nonzero direction can still be poorly supported by noisy measurements.

Read the relationship

A=UΣVᵀ, σ₁≥σ₂≥…≥0 A⁺=VΣ⁺Uᵀ; x̂=A⁺b

Columns of V are input directions, columns of U output directions. Σ⁺ reciprocates nonzero singular values and leaves zero ones at zero.

Work through an example

  1. Let A=diag(3,0) and b=(6,1). Then A⁺=diag(1/3,0).
  2. The pseudoinverse gives x̂=(2,0), with prediction (6,0).
  3. The residual (0,1) cannot be removed. Any second input coordinate gives the same prediction; the pseudoinverse chooses the shortest solution.

When it applies

Numerical rank needs a tolerance related to data and precision. Singular values are not generally the same as eigenvalues, and blind inversion of tiny values amplifies noise.

Check your understanding

Can a pseudoinverse recover an input component that never affects the observations?

No. It provides a conventionally selected solution, not new information about an invisible nullspace direction.

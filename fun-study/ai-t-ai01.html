AI, Learning and a Well-Defined Task

What exactly should this system predict, generate or decide?

The idea

Artificial intelligence includes rules, search and planning as well as learning from examples. Machine learning adjusts a model using data; deep learning uses multiple learned representations. Naming a technique is less important than specifying its inputs, outputs and success criteria.

A useful task definition includes the population the system will encounter, how labels or rewards are obtained, and a baseline that works without an elaborate network. Training minimises a chosen loss, but the deployed task may care about costs or failures the loss does not capture.

Read the relationship

ŷ=fθ(x); θ*=arg minθ (1/N)Σᵢℓ(fθ(xᵢ),yᵢ)

x is input, θ model parameters, ŷ prediction, y target and ℓ a per-example loss. N is the number of training examples.

Work through an example

  1. A house-price model returns a number, so a squared-error baseline may be meaningful.
  2. An image classifier returns class scores or probabilities and needs a classification protocol.
  3. A language model predicts a next-token distribution; fluent output alone does not establish factual accuracy.

When it applies

A favourable training objective is not a complete task evaluation. Compare with a simple baseline on independent, representative cases.

Check your understanding

Why define a baseline before building a large network?

It reveals whether complexity adds useful evidence and exposes tasks already solved by a simpler rule.

Complex Systems Lab / 17

One-dimensional cellular automata

Can eight local cases encode a complicated history?

Run this experiment →

The idea

A row of binary cells updates from each cell's left neighbour, its own state and its right neighbour. These three bits form one of eight cases. A rule number stores the eight next-state choices. Stacking generations reveals the space–time history.

The horizontal axis is space; downward rows represent successive times. A diagonal feature need not be a material particle.

Read the relationship

aᵢ⁺=rule(aᵢ₋₁,aᵢ,aᵢ₊₁)

Rule 30 and Rule 110 are different eight-entry lookup tables, not two parameter values in one force law.

Try this

  1. Run both rules from one live seed. Inspect a small patch and work out its next row before stepping the model.

When it applies

Finite width and periodic boundaries influence long runs. Visual complexity alone does not establish randomness, universality or computational power for an arbitrary rule.

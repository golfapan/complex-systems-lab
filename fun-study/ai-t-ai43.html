Retrieval, Tools and Agents

How can a model use evidence and actions outside its weights?

The idea

Retrieval-augmented generation supplies relevant information before or during answering. Tool calling delegates structured requests to programs. An agent combines observation, planning, action and feedback into a repeated process. These are system designs, not just larger language models.

Evaluate the components separately. A correct answer can fail because retrieval missed the key passage, a tool used the wrong argument or execution did not achieve the intended effect. Returned documents and tool text are evidence to inspect, not automatically trusted instructions.

Read the relationship

question → retrieval or tool → evidence → response or action → verification

A retrieval result is not itself a grounded answer; a tool request is not itself a successful action. Each transition needs an explicit interface.

Work through an example

  1. For course questions, retrieve the relevant original passage and show its source.
  2. If retrieval finds no supporting evidence, permit a clear statement of the gap.
  3. After a tool action, inspect the resulting state rather than claiming success merely because a request was issued.

When it applies

Permissions, retrieval coverage and verification bound the system's abilities. Fine-tuning and retrieval modify different parts of the information pathway.

Check your understanding

Why score retrieval recall separately from answer quality?

A generation failure and a missing-evidence failure require different fixes.

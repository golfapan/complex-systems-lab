The Jacobian: A Derivative Is a Linear Map

What is the matrix that carries small input changes into output changes?

The idea

For a differentiable multivariable function, one linear map predicts the first-order effect of every small input displacement. The Jacobian is the matrix of that map in chosen coordinates. Its rows correspond to outputs and its columns to inputs, making its dimensions part of the meaning.

The chain rule composes these local maps in the same order as the underlying functions. For a scalar loss, reverse-mode differentiation uses a Jacobian transpose to pass sensitivity backwards. Robot velocity mapping, uncertainty propagation and neural-network backpropagation all share this local structure, although they use it for different questions.

Read the relationship

f(x+δ)=f(x)+Jf(x)δ+o(‖δ‖) J(g∘f)=Jg Jf For y=f(x): ∇xL=Jfᵀ∇yL

A map from ℝⁿ to ℝᵐ has an m×n Jacobian. Gradients here are column vectors, fixing the transpose convention.

Work through an example

  1. Let f(x,y)=(x²+y,xy). At (1,2), J=[[2,1],[2,1]].
  2. For δ=(0.01,−0.02), Jδ=(0,0), so the first-order change vanishes.
  3. The exact change is (0.0001,−0.0002): higher-order terms remain despite the zero linear prediction.

When it applies

Partial derivatives existing separately do not ensure a full derivative. A locally singular Jacobian and global noninvertibility are related but distinct issues.

Check your understanding

If Jδ=0, must f(x+δ)=f(x) for a finite δ?

No. The linear contribution vanishes, but higher-order changes can still be nonzero, as the example demonstrates.

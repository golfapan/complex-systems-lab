Gradients, stochastic gradient descent, and the chain rule

How does a loss tell a model which parameter to change?

The idea

A gradient lists how a scalar objective changes when each parameter changes a little. Gradient descent moves in the negative-gradient direction, with a learning rate controlling the step size. The chain rule connects a final error to parameters through a sequence of intermediate calculations, making multilayer learning possible.

Stochastic gradient descent estimates the full gradient from a sampled batch. This saves computation and introduces variation, so an individual update need not reduce the full objective. Learning rate, feature scale, curvature, and optimizer state all influence the resulting path. A small gradient may indicate a minimum, a saddle, or simply poor scaling.

Read the relationship

θnext=θ−η∇J(θ); ∇w[½(wᵀx−y)²]=(wᵀx−y)x

η is the learning rate; a gradient has one component per parameter. The sample formula uses squared prediction error.

Work through an example

  1. Take J(w)=(w−3)², starting at w=0 with η=0.1.
  2. The first derivative is −6, so the next value is 0.6; the next derivative is −4.8, giving 1.08.
  3. The objective decreases from nine to 5.76 to 3.6864, illustrating two explicit updates rather than instant arrival.

When it applies

Large steps can overshoot or diverge. Neither SGD nor an adaptive optimizer guarantees a global minimum for a general nonconvex network.

Check your understanding

If a stochastic update temporarily raises the training loss, must the implementation be wrong?

No. Sampling noise and finite step size can raise loss on a particular update; inspect the overall procedure and independent checks.

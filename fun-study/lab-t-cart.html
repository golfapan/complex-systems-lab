Swinging up and balancing a cart-pole

How can a horizontal push first raise a pendulum and then balance it?

Run this experiment →

The idea

The cart's horizontal force influences the pendulum through coupled mechanical equations. An energy-based strategy can build swing amplitude, while a local LQR controller stabilizes the upright state. Switching between them illustrates why one local linear controller does not solve every starting condition.

Balancing and reaching the balancing region are separate tasks. A local approximation is useful precisely because its operating region is understood.

Read the relationship

state=(x,ẋ,θ,θ̇) near upright: F=clip(−K·error,−Fmax,Fmax)

The pendulum angle in this model is measured from downward; the upright target is π. The only actuator is a horizontal cart force.

Try this

  1. Start the swing-up action and watch when the control mode changes. Compare force saturation with the cart's motion.

When it applies

Attention: Compare, Weight and Mix

How does a token decide which other information to use?

The idea

Attention compares a query with keys to form scores, converts those scores into weights, then mixes value vectors. Matrix multiplication performs many comparisons at once. The weights depend on the current input, so the whole operation is generally nonlinear even though mixing fixed values with fixed weights is linear.

Scaled dot-product attention divides scores by the square root of key dimension before applying softmax. Each row represents one query's distribution over allowed keys; a mask can exclude future or otherwise unavailable entries. A large weight indicates a strong contribution within this computation, not automatically a trustworthy causal explanation.

Read the relationship

Attention(Q,K,V)=softmax(QKᵀ/√dk)V αi=exp(si)/Σjexp(sj); o=Σiαivi

For T tokens, Q and K are T×dk, V is T×dv and the score matrix is T×T. Softmax acts separately on each query row.

Work through an example

  1. One query has already scaled scores (ln3,0), so exponentiating gives (3,1).
  2. Normalisation produces weights (0.75,0.25).
  3. With values v₁=(2,0) and v₂=(0,4), the output is 0.75v₁+0.25v₂=(1.5,1).

When it applies

Attention weights resemble probabilities over choices but are not automatically calibrated probabilities of real-world events. Standard full attention's T×T score structure creates quadratic sequence-scale costs.

Check your understanding

Does attention always choose one value vector unchanged?

No. Softmax attention usually forms a weighted combination. In the example the output is neither of the two original values.

Matrices as Actions; Multiplication as Composition

What does a matrix actually do to a vector?

The idea

Think of a matrix as a machine that combines input coordinates into an output. Its columns show where the input basis directions go. This view turns a table of numbers into a geometric action and makes the dimensions in engineering and AI formulas easier to interpret.

Multiplying matrices chains actions together. In ABx, B acts first and A acts second; changing the order changes the overall operation in general. Transposing swaps input-output pairings, which is why reversing a product requires reversing the order of its transposed factors.

Read the relationship

A∈ℝ^(m×n), B∈ℝ^(n×p) ⇒ AB∈ℝ^(m×p) A(Bx)=(AB)x; (AB)ᵀ=BᵀAᵀ

The inner dimensions must match. Matrix multiplication is not element-by-element multiplication, even when both operations happen to be available.

Work through an example

  1. Start with x=(1,1). Stretch horizontally using S=diag(2,1), giving (2,1).
  2. Rotate 90° using R=[[0,−1],[1,0]], giving RSx=(−1,2).
  3. Reverse the actions: SRx=(−2,1). The two compositions differ.

When it applies

Associativity does not imply commutativity. For complex inner-product calculations, use a conjugate transpose rather than assuming a real transpose is enough.

Check your understanding

If W is h×d and x is a d-component column, what is the shape of Wx?

It is an h-component column: W maps a d-dimensional input into an h-dimensional output.

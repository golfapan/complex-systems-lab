Vector Fields, Paths and Potential Functions

When can an entire path integral be replaced by an endpoint difference?

The idea

A vector field assigns a direction and strength to each point. A work integral keeps only the component along a path's direction, while a scalar line integral adds density along arc length. Reversing direction reverses work, but does not change the mass of the same wire.

When F is a gradient, moving through the field accumulates changes of a potential, so only the endpoints matter. Checking curl is useful locally, but global path independence also depends on the domain. A hole can allow nonzero circulation around a loop even where curl is zero at every permitted point.

Read the relationship

∫C F·dr=∫ F(r(t))·r′(t)dt F=∇φ ⇒ ∫C F·dr=φ(B)−φ(A)

r(t) parametrises an oriented path from A to B. The scalar element ds measures length; the vector element dr includes direction.

Work through an example

  1. Let F=(2x,2y), the gradient of φ=x²+y².
  2. From A=(0,0) to B=(1,2), the potential changes from 0 to 5.
  3. Every suitable path between those endpoints has work 5; reversing it gives −5.

When it applies

Curl-free fields require suitable domain conditions, such as simple connectedness, to guarantee a global potential. Singularities cannot be ignored.

Check your understanding

Why can (−y,x)/(x²+y²) have zero curl away from the origin but nonzero loop circulation?

The punctured plane has a hole. Around the unit circle the work integral is 2π, preventing a single-valued global potential.

State-Space Sequence Models and Mamba

Can a compact recurrent state handle very long inputs?

The idea

A state-space model summarises preceding inputs through a recurrent state. Continuous equations can motivate a discrete update, but the sampling rule and parameterisation determine the actual sequence model. Fixed state size does not mean an unlimited amount of history is retained without loss.

Selective state-space models make parts of the update depend on current content. This differs from a fixed linear time-invariant system and changes convolution-based computation. Compare sequence models on the task, state capacity and real hardware rather than treating one asymptotic complexity as a universal ranking.

Read the relationship

hₜ=Āₜhₜ₋₁+B̄ₜxₜ; yₜ=Cₜhₜ

h is the memory state and x the current input. Time-varying subscripts can represent input-dependent parameters in a selective model.

Work through an example

  1. A scalar update h⁺=0.9h+x retains a decaying contribution from earlier input.
  2. Changing retention according to x can suppress irrelevant tokens while preserving another event longer.
  3. A task requiring exact retrieval of arbitrary old positions still needs an empirical test of that compressed state.

When it applies

Continuous-state intuition does not make the whole network a fixed physical ODE. Training parallelism, recurrent inference and content selection require separate analysis.

Check your understanding

Does constant state dimension guarantee exact recall of every earlier token?

No. Compression generally loses information unless the task and representation permit sufficient retention.

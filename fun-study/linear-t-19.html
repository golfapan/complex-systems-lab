Neural Networks: Matrix Forward and Backward Passes

Where do matrix products, nonlinearities and gradients each enter a neural network?

The idea

An affine layer mixes features using a matrix and adds a bias. An activation then introduces nonlinearity. Without nonlinear operations, stacking affine layers still produces only another affine map, regardless of how many intermediate layers are drawn.

Backpropagation applies the chain rule while respecting shapes. An elementwise activation rescales each incoming sensitivity; an outer product produces weight derivatives; a transpose passes sensitivity towards the input. These operations are not arbitrary programming conventions: they follow from how a small parameter or input change affects the loss.

Read the relationship

z=Wx+b; a=φ(z) gz=ga⊙φ′(z) ∇WL=gz xᵀ; ∇xL=Wᵀgz

For column input x∈ℝᵈ and W∈ℝ^(h×d), z and gz are h-component columns. The symbol ⊙ means elementwise multiplication.

Work through an example

  1. Take x=(1,2), W=(2,−1), b=1 and a=ReLU(Wx+b). Then z=a=1.
  2. With target zero and L=a²/2, the upstream derivative is 1; ReLU's derivative is also 1 here.
  3. Thus ∇WL=(1,2), ∇bL=1 and ∇xL=(2,−1)ᵀ.

When it applies

ReLU is not differentiable at zero; implementations use a chosen subgradient convention. Row-based batch notation changes where transposes appear, so establish dimensions before comparing formulas.

Check your understanding

Why is the weight gradient an outer product rather than a dot product?

It needs one entry for each output-input weight, giving an h×d matrix; gz xᵀ has exactly that shape.

MLPs, Parameters and Tensor Shapes

How do you know the arrays describe the network you intended?

The idea

A multilayer perceptron alternates affine transformations with elementwise nonlinearities. Choose a row- or column-vector convention and follow it consistently. Batch, feature and output axes have different meanings even if their sizes happen to match.

Shape checks are more than avoiding errors. Broadcasting can silently change a computation, and a mistaken reduction can mix examples. The same weights are normally shared across a batch: increasing batch size increases work and activation storage, not the number of learned parameters.

Read the relationship

X∈R^(B×d); H=σ(XW₁+b₁); Ŷ=HW₂+b₂

B is batch size, d input features, and each row represents one example. Bias vectors broadcast over examples, not over arbitrary axes.

Work through an example

  1. Use input width three, hidden width four and output width two.
  2. Parameters total 3×4+4+4×2+2=26, including biases.
  3. A batch of eight gives X shape 8×3, H shape 8×4 and Ŷ shape 8×2; the parameter count remains 26.

When it applies

Correct dimensions do not prove correct semantics. Record what each axis represents and inspect reductions, masks and broadcasting.

Check your understanding

Does changing batch size from eight to sixteen double the network's parameter count?

No. It changes how many examples share the parameters in one computation.

Recurrent Networks and Backpropagation Through Time

How can one set of weights process sequences of different lengths?

The idea

An RNN updates a hidden state from the current input and previous state. Parameters are shared across time, so sequence length changes computation and the gradient path rather than creating new weights at every position.

Training unfolds the recurrent computation into a graph and applies backpropagation through time. Truncating that graph saves resources but limits how far a gradient can connect earlier events to a later loss. Separate the sequence timestep, network layer and training iteration: they are different axes of the computation.

Read the relationship

hₜ=tanh(Wₓxₜ+Wₕhₜ₋₁+b)

xₜ is the current input and hₜ the evolving activation. Wₓ, Wₕ and b are trainable parameters shared across timesteps.

Work through an example

  1. Feed sequences of length five and fifty to the same recurrent cell.
  2. Both use the same weight matrices, but the longer sequence performs more updates.
  3. Its loss can involve products of many recurrent Jacobians, creating long-range gradient difficulties even without more parameters.

When it applies

Hidden states can lose useful information, and training may require masking or careful batching. Shared weights do not guarantee unlimited effective memory.

Check your understanding

Is hₜ normally a separate learned parameter for every position?

No. It is computed from inputs and previous state; gradients adjust the shared update parameters.

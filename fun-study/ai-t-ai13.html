Convolutional Networks

What does sharing a small image filter buy you?

The idea

A convolutional layer applies shared local weights across spatial positions. This encodes a preference for recurring local patterns while using far fewer parameters than unrelated dense connections at every pixel. Stride, padding and depth determine which information is combined.

Many deep-learning libraries implement cross-correlation without flipping the filter, despite calling it convolution. Translation equivariance is also affected by boundaries and downsampling; it is not the same as invariance to every shift, rotation or deformation.

Read the relationship

Hout=floor((H+2P−K)/S)+1

H is input size, K kernel size, P padding and S stride, for the ordinary unit-dilation case. Channels add another independent dimension.

Work through an example

  1. A 32×32 input with a 3×3 kernel, padding one and stride one retains size 32×32.
  2. With three input and sixteen output channels, weights total 3×3×3×16=432.
  3. Adding sixteen biases gives 448 parameters, shared over all output positions.

When it applies

This size formula changes with dilation and other conventions. Parameter sharing is an inductive bias, not evidence that every image task should use the same architecture.

Check your understanding

Does translation equivariance mean the output is identical after moving the input?

No. An equivariant output shifts correspondingly; an invariant output would remain unchanged.

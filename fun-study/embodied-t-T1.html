Begin with a physical task

What must the robot accomplish, and what would count as success?

The idea

A useful robotics question specifies an object, an action, sensing, available control and conditions that may change. 'Make the robot intelligent' does not define an experiment. A concrete task exposes which information and capabilities actually matter.

Write a one-paragraph task card before selecting a neural architecture. Include one condition that should make the task fail.

Read the relationship

task = initial conditions + action space + goal + constraints + test conditions

This is a conceptual or modelling relationship. Its role is to make the task and assumptions explicit.

Try this

  1. For inserting a peg, specify acceptable alignment error, insertion depth, maximum contact force and a success detector independent of the policy's own confidence.

When it applies

A successful demonstration in one arrangement is evidence for that arrangement, not yet general manipulation capability.

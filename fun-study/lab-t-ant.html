Complex Systems Lab / 05

Langton's ant

How can a tiny rule leave a surprisingly organized trail?

Run this experiment →

The idea

The ant reads the state of the square it occupies, turns left or right, changes that square's state, and moves forward. The environment records the ant's past actions, so future motion depends on a growing external memory even though the ant's own instruction set is small.

Deterministic rules can generate a long complicated transient. A repeated route is a property of the combined ant-and-grid state.

Read the relationship

(heading, cell state) → (new heading, new cell state) Then move one grid step.

The standard two-colour rule can be written RL. Longer strings define different multicolour state machines.

Try this

  1. Run the standard rule from a blank grid, then reset with another rule string. Compare how long disordered-looking motion lasts and whether a repeating route appears.

When it applies

This ant does not smell food, follow pheromones or optimize a route. Those mechanisms belong to different models elsewhere in the lab.

LSTMs, GRUs and Gated Memory

How does a recurrent model decide what to keep?

The idea

An LSTM uses a cell state with gates that regulate writing, retention and reading. A GRU uses a more compact gated hidden-state design. Gates depend on input and state, so they provide learned information pathways rather than fixed-duration storage.

An additive memory route can ease some long-range gradient problems, but names such as forget gate do not prove what information a trained model retains. Compare actual tasks under similar parameter and compute budgets, and inspect failures at different sequence lengths.

Read the relationship

LSTM cell: cₜ=fₜ⊙cₜ₋₁+iₜ⊙gₜ

c is cell state, f the forget gate, i the input gate and g candidate content. The complete LSTM also has an output gate and hidden state.

Work through an example

  1. Suppose the forget gate stays at 0.9 and no new content is written.
  2. After ten steps, the old contribution is multiplied by 0.9¹⁰≈0.349.
  3. Retention near one can preserve this route longer, but does not make the whole system an unlimited exact memory.

When it applies

Gates can saturate or retain irrelevant information. LSTM and GRU equations differ; one schematic should not be presented as both architectures.

Check your understanding

Does calling a component a memory gate establish that the network remembers the task-relevant fact?

No. Its learned behaviour must be evaluated on the task, with appropriate sequence-length controls.

Synchronizing oscillators

How can different natural rhythms lock into a shared pace?

Run this experiment →

The idea

An oscillator adjusts its phase according to the phase differences it senses. Coupling can pull slower oscillators forward and faster ones back. Natural-frequency variation competes with this adjustment, so increasing coupling does not simply set every phase to the same value.

A coherent population can retain phase offsets. The spread of natural frequencies matters as much as the numerical value of K.

Read the relationship

θ̇ᵢ=ωᵢ+(K/N)Σⱼsin(θⱼ−θᵢ) r=|N⁻¹Σ exp(iθⱼ)|

ωᵢ is a natural frequency; K is coupling strength. The order parameter r measures phase concentration, not position clustering.

Try this

  1. Increase K while observing both the points on the phase circle and r. Compare frequency locking with perfectly identical phases.

When it applies

The finite sample and chosen frequency distribution matter. The demonstration does not measure a universal critical coupling for every oscillator network.

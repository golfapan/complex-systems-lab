Sequence-to-Sequence Models and Early Attention

How can an output sequence have a different length from its input?

The idea

An encoder reads the input, and a decoder produces an output sequence. Compressing everything into one vector can become a bottleneck. Cross-attention allows each decoder step to revisit input representations instead of relying only on one fixed summary.

Teacher forcing supplies the correct previous output during training. Free generation instead uses the model's own earlier choices, so the histories can diverge. Evaluate generated sequences, not only next-step predictions made with perfect prefixes, when the real task requires autonomous output.

Read the relationship

p(y|x)=Πₜp(yₜ|y₁,…,yₜ₋₁,x)

x is the input sequence and y the output sequence. The conditional probability uses all permitted input information and the output prefix.

Work through an example

  1. A translation input may contain seven tokens while its target uses ten.
  2. The decoder is not required to align output position three with input position three.
  3. A mistaken early generated token changes later prefixes, which can reveal failures hidden by teacher-forced evaluation.

When it applies

Attention does not by itself solve every alignment or memory problem. Training and inference must specify available context and stopping rules.

Check your understanding

Why can teacher-forced scores exaggerate generation quality?

The model receives correct histories during scoring that it may not produce for itself.

Make the action contract explicit

Can two models' action vectors be compared or exchanged?

The idea

An action contract specifies coordinates, reference frame, units, absolute versus relative commands, command horizon and execution semantics. Without it, a policy's numerical output has no reliable physical interpretation.

Write an example input/output pair and describe exactly how it changes the robot.

Read the relationship

action contract = representation + frame + units + timing + controller semantics

This is a conceptual or modelling relationship. Its role is to make the task and assumptions explicit.

When it applies

Changing an action adapter can alter behaviour even with identical network weights. Interface compatibility is more than matching tensor shapes.

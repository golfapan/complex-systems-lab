Trees, bagging, random forests, and boosting

Why can several imperfect models work better together?

The idea

A decision tree partitions feature space using a sequence of questions. A regression leaf predicts an average; a classification leaf estimates class frequencies or related scores. Deep trees can fit complex patterns but are sensitive to the sample, so controlling depth and leaf size can be important.

Bagging averages models fitted to resampled data to reduce variation. Random forests add feature randomization to make trees less alike. Boosting builds a sequence of models that improve a current predictor, with learning rate and iteration count controlling the process. Averaging and sequential correction are distinct strategies, not interchangeable names for ensembles.

Read the relationship

Var(T̄)=σT²[ρ+(1−ρ)/B]; boosting: Fm=Fm−1+ηhm

The variance formula assumes equally variable predictions with common pairwise correlation ρ; B is the number averaged.

Work through an example

  1. Suppose one tree's prediction variance is four and pairwise correlation is 0.5.
  2. Averaging ten gives 4[0.5+0.5/10]=2.2, rather than the 0.4 obtained with independent predictions.
  3. As the ensemble grows, this simplified variance approaches two: adding highly similar trees has diminishing returns.

When it applies

Choose depth, learning rate, and iteration count using validation. Resampling must respect time and group structure rather than mixing dependent rows freely.

Check your understanding

Does adding more trees always remove all prediction error?

No. Correlated variation, bias, noise, and limitations of the input information can remain.

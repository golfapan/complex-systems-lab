Losses, Probabilities and Cross-Entropy

Why can two correct classifications have different losses?

The idea

Logits are unnormalised scores. Softmax turns them into a categorical distribution, and cross-entropy evaluates the probability assigned to the observed label. Accuracy keeps only the winning class, so it discards confidence information that the loss retains.

A loss should match the prediction object and data model. Regression, classification and contrastive learning need different objectives. Numerical stability matters too: combining log-softmax with the loss avoids unnecessary exponentials and prevents errors caused by applying softmax twice.

Read the relationship

pⱼ=exp(zⱼ)/Σₖexp(zₖ); L=−log pᵧ

z contains logits and y indexes the true class. Subtracting a common maximum logit leaves softmax probabilities unchanged and improves numerical stability.

Work through an example

  1. A prediction assigning probability 0.5 to the true class has loss about 0.693.
  2. Assigning 0.9 reduces that loss to about 0.105.
  3. Both may select the correct argmax, yet their probability statements differ substantially.

When it applies

Cross-entropy and accuracy are not calibration guarantees. A model can rank classes correctly while systematically overstating its certainty.

Check your understanding

Why not apply softmax before a library loss that already includes it?

The repeated transformation changes the intended objective and can weaken or distort the gradients.

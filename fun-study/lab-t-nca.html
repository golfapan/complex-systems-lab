Complex Systems Lab / 24

Learning a local growth rule

Can the same tiny network at every grid cell learn to build a target shape?

Run this experiment →

The idea

Each cell stores visible and hidden channels, senses local features and applies a shared neural update. Training unfolds several updates and adjusts the shared parameters so that the final image matches a target. The simulation state changes during growth; parameters change during training.

Matching a target after a fixed number of steps is a narrower achievement than maintaining it forever or regenerating after damage.

Read the relationship

hᵢ⁺=hᵢ+fθ(local perception) L=mean squared error after a fixed rollout

This miniature system uses a 12×12 grid, four channels and a small hidden layer, with a fixed twenty-step training rollout.

Try this

  1. Train for a while and inspect the loss. Pause training to see how state evolution differs from parameter learning.

When it applies

The target is a small disk. This is not a reproduction of the published lizard model or a trained damage-regeneration experiment.

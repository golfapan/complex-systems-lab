Ant-inspired route search

Can many biased random tours discover a shorter route?

Run this experiment →

The idea

Agents construct tours by sampling possible next cities. Existing pheromone and distance bias the choice. Shorter completed tours deposit more pheromone, while evaporation prevents old decisions from remaining equally influential forever.

A shorter distance can greatly increase a candidate's weight, but competing candidates determine the actual probability.

Read the relationship

P(i→j)∝τᵢⱼ/dᵢⱼ³ τ⁺=(1−ρ)τ+deposits

The local implementation uses a cubic distance preference. A weight becomes a probability only after normalizing over currently available cities.

Try this

  1. Compare the best route early and later. Change evaporation and see how quickly memory concentrates or disappears.

When it applies

Finite search does not guarantee the globally shortest tour. This is a stochastic optimization heuristic, not the colour-switching Langton's ant model.

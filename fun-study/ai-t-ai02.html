One Neuron and an Activation Function

Where does a network acquire its nonlinearity?

The idea

A neuron forms a weighted sum, adds a bias, then applies an activation. The weights determine which input directions matter; the bias shifts the boundary. Without nonlinear activations, stacking affine layers still produces one affine mapping.

An activation changes which response patterns a multilayer model can represent. ReLU clips negative preactivations to zero. It is not differentiable at zero, so software adopts a derivative convention there. Mathematical representation, the chosen derivative convention and the optimisation process should not be confused.

Read the relationship

z=wᵀx+b; a=σ(z); ReLU(z)=max(0,z)

z is the preactivation and a the output. The dot product requires matching input and weight dimensions; b is a scalar for one neuron.

Work through an example

  1. Take x=(1,2), w=(2,−1) and b=1.
  2. The weighted sum is 2×1−1×2+1=1, so ReLU returns one.
  3. Changing only b to −1 makes z=−1 and the output zero, shifting which inputs activate the neuron.

When it applies

One activation does not guarantee a learnable or useful network. Saturation, dead units and poor scaling can still obstruct training.

Check your understanding

What happens if every activation is replaced by the identity?

Compositions of affine layers collapse to a single affine map; depth alone adds no nonlinear boundary.

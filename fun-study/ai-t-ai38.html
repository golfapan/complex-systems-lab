Supervised Fine-Tuning and Instructions

How does a continuation model learn to follow a request?

The idea

Supervised fine-tuning trains on prompts paired with demonstrated responses. A chat template defines their token-level structure, and loss masking determines which tokens are learning targets. These details can be as important as adding more examples.

Fine-tuning changes weights; it does not install an infallible external knowledge database. Evaluate held-out instructions, factual behaviour, formatting and forgetting. The training and inference templates must agree on the roles and boundaries the model is expected to recognise.

Read the relationship

L_SFT=−Σ over response positions t log pθ(yₜ|prompt,y₁,…,yₜ₋₁)

The response-only sum is one common choice, not the only possible loss mask. Prompt and padding tokens require explicit treatment.

Work through an example

  1. Encode a prompt and its ideal answer using the intended chat format.
  2. Mask out positions that are not intended response targets and verify the shifted labels.
  3. Compare the base and tuned model on tasks excluded from the demonstrations, including tasks where unwanted forgetting might occur.

When it applies

Including test questions in demonstrations compromises evaluation. A lower fine-tuning loss does not establish reliable instruction following outside the training style.

Check your understanding

Can a mismatched chat template weaken an otherwise useful fine-tune?

Yes. The model may not recognise the same role and response boundaries at inference.

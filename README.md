# 复杂系统实验室

从简单规则到复杂世界。8 个基础实验 + 12 组拓展中的 18 个模型，共 26 个模型。
首页 → 知识地图 → 六个主题、46 条联系、数学定位表、知识卡及八阶段学习路线。
基础实验各有独立页面；拓展实验由 extensions.html 的不同链接直接进入。

所有模型在浏览器内计算，无需 Python、后端或安装依赖。
需要现代浏览器、JavaScript 和 Canvas；分形使用 Web Worker。
手机和平板可用，速度取决于设备。知识地图与数学表可横向滑动。

## 发布到 GitHub Pages

将本目录全部内容放到独立仓库 main 分支根目录。
Settings → Pages → Deploy from a branch → main → /(root)，保存。
分享 GitHub Pages 返回的网址。当前交付包并不表示已经发布成功。

保持所有文件在同一层；不要只传 HTML，必须包含 CSS、JavaScript、
fractal-worker.js 和 .nojekyll。链接均为相对路径，支持项目子路径。
首页为 index.html，知识地图为 map.html，无需额外构建步骤。

## 教学范围

本网站是交互式知识地图与教学实验，不是完整复杂系统教材。
模型、数值方法和理论背景分别说明；应用举例不是工程验证结果。
圆柱流与热对流尚无网格收敛及完整基准验证；临界常数有适用条件。
NCA 实际训练 12×12 小网格、固定 20 步目标；未实现论文完整再生训练。
来源与后续补充方向见知识地图和各实验页。

从鱼数到 Logistic 模型

1 · 繁殖与竞争

Nₙ 是今年的鱼数，Nₙ₊₁ 是明年的鱼数，r 是资源充足时的数量倍数。只考虑繁殖，便有：

Nₙ₊₁ = rNₙ

鱼越多，资源竞争越强。设 K 为拥挤尺度，假设增长倍数随鱼数线性下降：

增长倍数 = r(1−Nₙ/K)
Nₙ₊₁ = rNₙ(1−Nₙ/K)

2 · 归一化

令 xₙ=Nₙ/K，得到鱼数比例：

xₙ₊₁ = r xₙ(1−xₙ)

r xₙ 表示繁殖作用，1−xₙ 表示竞争造成的折减。

3 · 看怎样的演化？

从 x₀=0.2 开始，每次固定 r，反复计算下一年。本页 r 可调 2.5–4，x 保持在 [0,1]。“单步”算一年，“重新开始”回到初值。

4 · 稳定性怎样算？

要判断的事情：鱼数偏离平衡一点后，接下来会靠近平衡，还是越离越远？下面研究平衡点附近的小偏差。

参考原文的 Stability 与周期循环讲解。原文的增长参数 λ，在本页写作 r。

① 找到平衡数量。设 x∗ 是每年保持相同的数量比例：

x∗ = r x∗(1−x∗)
解得 x∗=0，或 x∗=1−1/r。

以下先看非零平衡 x∗=1−1/r。

② 定义偏差。δₙ 是第 n 年的数量与平衡数量之差，δₙ₊₁ 是下一年的偏差：

δₙ = xₙ−x∗，所以 xₙ=x∗+δₙ。
δₙ₊₁ = xₙ₊₁−x∗。

例如平衡值是 0.6，当前值是 0.61，则偏差 δₙ=0.01。

③ 把偏差代进原方程。用 x∗+δₙ 代替 xₙ，再展开：

xₙ₊₁ = r(x∗+δₙ)(1−x∗−δₙ)
　　　 = r x∗(1−x∗) + r(1−2x∗)δₙ − rδₙ²
　　　 = x∗ + r(1−2x∗)δₙ − rδₙ²
两边减去 x∗：
δₙ₊₁ = r(1−2x∗)δₙ − rδₙ²。

δₙ 很小时，δₙ² 更小。先保留一次项：

δₙ₊₁ ≈ r(1−2x∗)δₙ = f′(x∗)δₙ，
其中 f(x)=rx(1−x)，f′(x)=r(1−2x)。

这就是原文的一阶泰勒展开：在平衡点附近，用切线近似函数。

④ 为什么看导数的绝对值？记 a=f′(x∗)，偏差每一步约乘一次 a：

δ₁≈aδ₀，δ₂≈a²δ₀，…，δₙ≈aⁿδ₀。
条件小偏差的变化结论
|a|<1幅度逐步缩小，趋向 0平衡点局部渐近稳定
|a|>1幅度在附近逐步放大平衡点不稳定
|a|=1一次项处于临界继续分析高阶项

a 为负，偏差会在正负之间交替；|a| 决定幅度怎样变化。

⑤ 代入本模型，求稳定范围。

a = r(1−2x∗)
　= r[1−2(1−1/r)]
　= 2−r。
稳定条件：|2−r|<1
⇒ −1<2−r<1
⇒ 1<r<3。

结论：1<r<3 时，非零平衡点附近的偏差逐渐消失；r>3 时，该平衡点失稳。

⑥ 看两个数值例子。

r=2.5：x∗=0.6，a=−0.5。
小偏差约为：0.01 → −0.005 → 0.0025 → −0.00125 → …
r=3.2：x∗=0.6875，a=−1.2。
小偏差起初约为：0.01 → −0.012 → 0.0144 → −0.01728 → …

第一组左右交替、逐渐靠近平衡；第二组在平衡附近越来越远。上面的数列使用一次近似，完整迭代还包含 −rδₙ²。

更严格地看：二次项也能一起控制

令 q 为 |a| 与 1 之间的一个数，选足够小的邻域 |δₙ|≤η，使 rη≤q−|a|。用上面的精确偏差式：

|δₙ₊₁| = |aδₙ−rδₙ²|
　　　　 ≤ (|a|+rη)|δₙ|
　　　　 ≤ q|δₙ|。

因为 q<1，偏差保持在这个邻域里，并按几何倍数趋向 0。这给出了局部渐近稳定的证明。

⑦ 如果长期在两个数之间循环呢？设循环是 A→B→A。走完两步后回到 A，把两步合成 g(x)=f(f(x))：

g′(A)=f′(B)f′(A)。
两周期稳定条件：|f′(B)f′(A)|<1。

每一步的偏差先乘 f′(A)，再乘 f′(B)；一整圈乘积的绝对值小于 1，偏差就逐圈缩小。例如 r=3.2 时，A≈0.5130、B≈0.7995，两步乘积约为 0.16，循环局部渐近稳定。

与离散控制系统对应：δₙ₊₁=aδₙ 中的 a 相当于离散极点，|a|<1 就是极点位于单位圆内。

混沌：典型轨道在有界范围内持续不规则变化，并对初值敏感。判断时结合长期轨道与扰动增长指标。

λ：扰动增长指标

λ 是 Lyapunov 指数，表示微小扰动的长期平均增长率。λ<0 表示平均收缩，λ>0 表示平均放大；接近 0 时需延长计算。

λ ≈ (1/m) Σⱼ₌₀ᵐ⁻¹ ln|r(1−2zⱼ)|

zⱼ 是按同一规则计算的诊断轨道，m 是采样数。本页从 0.234567 出发，丢弃前 500 步，再平均 2000 步；结果为有限样本估计。

模型采用年度离散更新。初值、竞争函数与参数共同决定结果。参考：MIT OCW · Logistic Equation。

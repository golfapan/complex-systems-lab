从一个有趣的问题开始

把生命游戏的开关，换成调光器

刚才的棋盘里，每格只能活或死。如果像调灯光一样，允许每格从微弱到旺盛，邻居的影响也不只来自贴身的几格，会发生什么？画面可能出现柔软的团块，聚拢、扩散或逐渐消失，看起来像一小片会变化的生命。本页是 Lenia 型教学模型；像生物的外形，来自活性场的更新，不代表真的有生命。

前四项用同一组规则，只换初始条件；消退对照另用较高 μ 和较窄 σ。都是独立构造的几何种子，不保证形成特定生物或永久存活。

数值精度：时间小步 Δt

小步长通常更接近连续模型，也需要更多计算；大步长可能改变图案。比较时使用相同的模型时间 t。它与播放速度是两件事。

怎样建立这个模型？

  1. 从现象开始：为什么这样建模

    把开关状态改成连续活性，再加入有距离权重的感知，会发生什么？

    二维周期格面，用单一活性场表示局部状态，细胞内部结构省略。

    将生命游戏的0/1开关改成0到1之间的活性，并让附近不同距离具有不同权重，就得到一种连续值的局部规则。这里不是把康威每代画面做平滑插值，而是重新定义“感知多少”和“怎样增长”。

    本站是 Lenia 型的单通道教学实现：环形感知核、钟形增长窗口、最后限制活性范围。它借用人工生命的设计思想；“活性增长”是规定的局部动力学，不是质量守恒或真实代谢定律。

  2. 先认清每一个量

    “状态”是此刻必须记住、才能继续算的量；“输入”从外部给定；“参数”在一次运行中固定；“输出／辅助量”由已有状态算出。下面按这个实验分别对应。

    符号它表示什么在模型里做什么单位或范围
    Aᵢ某格当前活性，0为空，1为上限状态；完整状态是全部格的A无量纲，0至1
    Kⱼ相对位置j的感知权重；所有权重相加为1固定邻域关系无量纲
    Uᵢ周围活性的加权平均，U=K*A由当前状态计算的感知量无量纲
    G(Uᵢ)感知量对应的增长率，正为增加、负为减少更新规则的输出活性/模型时间
    μ、σ、R增长窗口中心0.15、宽度0.025、核半径10格模型参数活性、活性、格
    Δt默认0.1；增长率乘它才变成此次活性改变量计算推进长度模型时间
    对照本页默认值与可调参数

    默认 μ=0.15、σ=0.025，核半径10，Δt=0.1；μ、σ 决定生长窗口，Δt 控制数值推进。

  3. 一步、一格和随机数分别是什么

    一步代表什么：一次计算加上Δt=0.1模型时间；它不是生命游戏的一整代，改变Δt应在相同模型时间比较。

    空间怎样表示：128×128格，左右上下相接；默认权重集中在距本格约R/2的环带，R=10格。

    随机数在哪里出现：blob等几何初态无持续随机项；noise种子含固定种子的随机初值，之后由同一规则确定。

  4. 从原理和关系推到方程

    1. 先规定哪些距离最值得感知

      令q为距离/R；本实现取q<1范围内的高斯环形权重exp[−½((q−0.5)/0.15)²]，范围外为0，再除以所有原始权重之和。归一化使U仍在0到1之间。

    2. 用加权平均替代“数活邻居”

      将各邻格A乘其K后相加得到U。本格A与邻域U不是同一量：一个活性很低的格，也可能被活性适中的邻居包围。

    3. 把适宜生长窗口写成增长函数

      以μ为中心，用σ控制宽度；把高斯值乘2再减1，使中心增长率为+1、远离窗口时趋近−1。这里的指数并非概率密度，不要求面积为1。

    4. 把增长率累积，再遵守范围限制

      先A+ΔtG，再clip到[0,1]。裁剪改变靠近上下限的有效变化，是当前模型的一部分；FFT只是更快算同一个周期卷积。

  5. 编号方程：逐条读懂，再看计算顺序

    先把本模型要用的式子放在一起。括号编号只在本模型内使用；物理关系、规则定义与数值推进的区别在下面逐条说明。

    （1）
    Kⱼ = K原始,j / ΣₖK原始,k；ΣⱼKⱼ=1
    （2）
    Uᵢ = (K*A)ᵢ = ΣⱼKⱼ Aᵢ₋ⱼ
    （3）
    G(Uᵢ) = 2 exp[−(Uᵢ−μ)²/(2σ²)] − 1
    （4）
    Aᵢ⁺ = clip(Aᵢ + Δt G(Uᵢ), 0, 1)

    每个式子在说什么？

    式（1）

    邻居权重只决定怎样汇总附近活性；半径和环形轮廓决定看谁、看多重。

    式（2）

    *代表这个加权汇总操作，即卷积；对称环核使正负位移写法等价。所有A来自旧场。

    式（3）

    U等于μ时增长最快；偏离μ约一个σ时增长已减弱；足够远时为负。

    式（4）

    先求改变量，再限制上下限。clip(z,0,1)就是小于0取0、大于1取1，其余不变。

    程序怎样把它们接成一步？

    1. 由旧A场算全部U；卷积中跨边界的邻居从另一侧取。
    2. 逐格把U代入同一增长函数G。
    3. 逐格计算A+ΔtG并裁剪，形成新场。
    4. 推进模型时间；若显示U或G，重新根据新场计算显示量。

  6. 从哪里开始，怎样算一步

    128×128 周期网格，几何种子；FFT 计算周期卷积，再作投影 Euler 更新。裁剪是本实现规则的一部分。

    同一格的A和U有何区别？

    假设所选格A=0.4，邻域加权结果U=0.15。采用默认μ=0.15、σ=0.025、Δt=0.1。

    1. U=μ，所以指数为0；G=2×1−1=1。
    2. 本次增长量是ΔtG=0.1，而不是直接把A改成U；新A=0.4+0.1=0.5。
    3. 若邻域U变成0.20，则(U−μ)/σ=2，G=2exp(−2)−1≈−0.72933。
    4. 相同旧A=0.4此时变为0.32707；若旧A只有0.02，计算得到负值，则裁剪为0。

  7. 怎样核验 · 参考资料

    下面是可以自己做的核验及预期，不表示所有现实用途都已经被验证。

    • 把全场设为同一个A值，检查感知U。

      应看到：归一化核应给U=A；核权重和偏离1会直接改变增长窗口的位置。

    • 固定初态和核，只把Δt从0.1改为0.05，在同一t比较。

      应看到：短期应趋近；形态是否持久需另看长期，不能只比较相同更新次数。

    先预测，再只改一个条件

    固定 μ、σ，只减半 Δt；同一模型时间的团块是否仍存在？

    形态类似微生物不等于具有真实生命机制；活性总和一般不守恒。核、增长函数、步长都应随模型一起说明。

UNDER THE PATTERN

这个连续模型，到底怎样建立和求解？

这是一个独立实现的 Lenia 型教学模型：单个活性场、环状邻域、钟形增长函数。它不是康威规则的唯一连续版本，也不是完整 Lenia 生物库的复刻。下面先讲连续模型，再讲电脑使用的差分近似。

01 · 状态不再只有 0 和 1

a(x, y, t) ∈ [0, 1]

a 是位置 (x, y) 在时间 t 的活性强度。0、0.2、0.73、1 都允许。二维空间不意味着 a 必须拆成两个分量：这里 a 是一个随 x、y 改变的标量场，和温度场相似。

理想模型中空间与时间连续；本页电脑计算仍采用 128 × 128 空间网格和有限时间小步。画面平滑只是显示方式，不会增加真实的计算分辨率。“总活性”是所有格点 a 的和，不是细胞数，也不是守恒质量。

02 · 先感知周围，再决定增长

U(x, y, t) = (KR ∗ a)(x, y, t)U(x, t) = ∫ KR(x − z) a(z, t) dzG(U) = 2 exp[−(U − μ)² / (2σ²)] − 1

第二行把二维位置简写为 x、z，积分在整个周期空间上进行。K 是非负、归一化的环状权重，所有权重加起来为 1，所以 U 是一个加权平均。距离约 R/2 的邻居权重最大，超过 R 的不计；R 越大，感知范围越大。

本页具体核形状是：令 r = 距离/R；当 r < 1 时，权重正比于 exp[−(r − 0.5)²/(2 × 0.15²)]，再归一化。0.5 和 0.15 是固定的建模选择，不是自然常数。

钟形函数 G 把邻域 U 变成增长率：恰好 U = μ 时增长最快，G = +1；太稀或太密时 G 趋向 −1。G > 0 的窗口为 |U − μ| < 1.177σ。μ 决定窗口中心，σ 决定宽度；这不只是“越多越好”的正反馈。

例如默认 μ = 0.15、σ = 0.025，约在 U = 0.121～0.179 时增长。注意：当 μ 很低、σ 很宽，使 G(0) > 0 时，空白处也会自发增长；并非所有参数下“全零”都是稳定静止状态。

03 · 真正的微分方程，还需要边界约束

∂a/∂t = G(U)　当 0 < a < 1∂a/∂t = max(0, G(U))　当 a = 0∂a/∂t = min(0, G(U))　当 a = 1

内部按增长率增加或减少；到 0 后不能继续减少，到 1 后不能继续增加。这是带投影约束的连续动力系统，边界处并非全局光滑。不能只写 ∂a/∂t = G(U) 却忘记范围限制。

它属于非局部积分—微分模型：时间用微分，空间作用通过邻域积分实现。它没有前一个反应—扩散实验的 D∇²a 项，因此不宜直接把它称为相同的扩散 PDE。这里的“感知邻域”也不是物质流动。

04 · 电脑怎样把微分方程算出来？

Unij = Σpq wpq ani−p,j−q，Σw = 1an+1ij = clip[0,1](anij + Δt G(Unij))tn+1 = tn + Δt

先用同一时刻的全部格点算 U，再同时更新所有 a。clip 把越界的数截回 [0,1]，对应上面的约束；这一截断是模型的一部分。周期索引使上下、左右边缘相接。程序用 FFT 加速同一个卷积和，并没有加入新的动力学。

这就是投影显式 Euler 差分近似。在内部，(an+1 − an)/Δt ≈ G(Un)。Δt 趋小时才是在逼近连续时间；把动画播放得更快，只是更快计算这些小步。

空间也离散了：要研究空间收敛，需要增加网格，并按相同物理范围缩放 R 和初始条件；本页只提供时间步长控制。不能把固定网格上的结果当作已经验证了空间连续极限。

05 · 参数、数值方法、播放设置要分清

调整项改变什么怎样比较
μ、σ增长规律，属于模型固定起点、R 和 Δt，只改变一项
R邻域作用的空间尺度观察团块尺寸、裂解及相互作用
初始图案初始条件前四个预设的 μ、σ、R 相同
Δt时间近似精度比较相同 t，而不是相同步数
演化速度、放大、显示层计算节奏和观察方式不改变每一步的更新公式

本页不同于自然界中的生物模型，没有实验标定或守恒机制。“生命”只是对自组织图案的比喻；消失、振荡、扩张、碎裂都可以是值得研究的结果。

06 · 从控制角度分析

先在内部考虑均匀场 a = a₀。归一化卷积给出 U = a₀，均匀平衡要求 G(a₀) = 0，因此候选值为 a₀ = μ ± σ√(2 ln 2)，并且必须落在 (0,1)。全零和全一还需要单独检查约束下的增长方向。

a = a₀ + δa∂δa/∂t ≈ G′(a₀) (KR ∗ δa)λ(k) = G′(a₀) K̂R(k)

这里忽略高阶小量并假定没有触及 0、1 边界。每个空间 Fourier 模态 k 都有自己的增长率 λ：实部为正时放大，为负时衰减。环状核的 Fourier 系数可能有正有负，因此不同空间波长可能表现不同。这说明线性分析仍能判断小扰动的初期发展。

但扰动变大后，钟形非线性、空间耦合及边界截断共同决定最终形态；线性化不能单独算出最终“长成什么”。这和两变量 Turing 模型的分析思路相通，具体的稳定性条件并不相同。

建议做四个小实验
  1. 看因果链：暂停，点击团块边缘，依次切换 a、U、G，理解为何某处增长、另一处消退。
  2. 改模型：团块起点重播，只把 μ 从 0.15 改到 0.16；再恢复，只把 σ 从 0.025 改到 0.03。观察同一模型时间下的区别。
  3. 查步长：分别用 Δt = 0.10、0.05、0.02 从头演化到接近相同 t。早期形状应更容易比较，长时间差异可能包含数值误差及非线性放大。
  4. 加小扰动：暂停后点一个位置加 0.01，继续观察。当前只展示被扰动的一次轨迹；要严谨判断敏感性，需要保存未扰动对照，不能仅凭图案复杂就称为混沌。

07 · 与原来生命游戏的关系

康威生命游戏直接定义“下一代是什么”，没有可自由缩小的 Δt；这里先定义连续时间增长率，再用 Δt 近似求解。两者都可以写成离散更新式，但其来源不同。把康威动画加速或给格子加渐变，不会自动变成这个微分方程。

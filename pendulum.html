把扫帚立在手心，为什么要不停纠正？

你试过把扫帚倒立在手心吗？它稍微歪一点，往往越倒越快，你必须不断观察、及时纠正。这个实验保留“发现偏差再纠正”的核心，但装置不同：支点固定，由关节电机直接施加力矩。你来决定电机纠正得多狠、刹车有多强，看看它能否扶正，还是来回晃个不停。

怎样建立这个模型？

从原理、变量和关系出发，读懂编号方程，再亲手算一步。 查看建模方法与常见关系 →

  1. 从现象开始：为什么这样建模

    固定支点的倒立摆，怎样用关节力矩保持直立？

    单质点、无质量刚杆、固定支点、平面运动；驱动直接施加关节力矩。

    想让一根向上竖着的杆保持不倒，先问重力、摩擦和电机各产生多大力矩。杆端是质量m的质点，杆长l，支点固定；杆本身无质量。这里电机直接对关节施加力矩，不是靠小车移动支点。

    物理部分来自转动版牛顿第二定律；PD反馈是我们设计的控制办法。角度θ从竖直向上量起，所以小的正偏角会被重力继续推大。这个坐标约定决定了重力项的正号。

  2. 先认清每一个量

    “状态”是此刻必须记住、才能继续算的量；“输入”从外部给定；“参数”在一次运行中固定；“输出／辅助量”由已有状态算出。下面按这个实验分别对应。

    符号它表示什么在模型里做什么单位或范围
    θ，ω偏离直立的角度与角速度，ω=θ̇随运动变化的状态rad；rad/s
    τ电机施加的关节力矩输入，由控制律算出N·m
    m，l，g质量、杆长、重力加速度；默认1、1、9.81物理参数kg；m；m/s²
    I=ml²，b转动惯量；黏性阻尼系数，默认b=0.12由结构确定/给定的参数kg·m²；N·m·s/rad
    Kp，Kd，τmax位置增益30、速度增益6、最大力矩15控制设计参数N·m/rad；N·m·s/rad；N·m
    对照本页默认值与可调参数

    默认 m=l=1，g=9.81，b=0.12，Kp=30、Kd=6，力矩限幅15；控制增益是设计参数。

  3. 一步、一格和随机数分别是什么

    一步代表什么：物理模型连续变化；程序每1/240秒用RK4前进一次。这个时间步是计算设置，不是重力规律。

    空间怎样表示：没有空间网格，只追踪一个摆角和一个角速度；转满一圈后用等价角误差计算控制。

    随机数在哪里出现：默认没有逐步随机扰动；15°初角和零角速度给定后，轨迹由方程确定。

  4. 从原理和关系推到方程

    1. 由重力得到力矩

      重力大小mg，垂直于杆的分量为mg sinθ，乘力臂l得到+mgl sinθ。阻尼反对转动，给−bω；再加电机τ。

    2. 合力矩变成角加速度

      把三种力矩相加，并令其等于Iω̇。除以I可求出此刻角加速度；再加θ̇=ω，就把二阶方程改成两个一阶状态方程。

    3. 把控制目标接到输入上

      目标是θ=0、ω=0。位置偏得越多给越强反向力矩，速度越大给越强制动力矩；两者合成后截在±15内。

    4. 用局部方程检查是否能稳住

      未饱和且θ很小时sinθ≈θ；代入PD式得到有效刚度Kp−mgl。刚度与总阻尼都为正，局部线性极点才在左半平面。

  5. 编号方程：逐条读懂，再看计算顺序

    先把本模型要用的式子放在一起。括号编号只在本模型内使用；物理关系、规则定义与数值推进的区别在下面逐条说明。

    （1）
    I=ml²；Iω̇=mgl sinθ−bω+τ
    （2）
    θ̇=ω；ω̇=(mgl sinθ−bω+τ)/I
    （3）
    e=wrapAngle(θ)；τ=clip(−Kp e−Kd ω，−τmax，τmax)
    （4）
    Iδ̈+(b+Kd)δ̇+(Kp−mgl)δ=0

    每个式子在说什么？

    式（1）

    左侧是转动惯量乘角加速度；右侧依次是重力、阻尼、电机力矩。三个来源必须在同一正方向下相加。

    式（2）

    给定当前θ、ω和输入τ，这两式就给出两个状态此刻的变化率。变化率还不是下一时刻的状态。

    式（3）

    e取离直立最近的等价角；clip表示电机力矩限幅。负号表示反对角误差和角速度，不表示重力本身发生改变。

    式（4）

    δ是直立附近的小扰动。默认Kp−mgl=20.19>0，总阻尼6.12>0；这个判断限于未饱和的小范围。

    程序怎样把它们接成一步？

    1. 读取旧状态θ、ω，用当前状态算误差e和限幅后的力矩τ。
    2. 把τ代入两条状态方程，得到角速度和角加速度。
    3. RK4在一步中还会计算三个中间状态，并在这些状态重新求反馈；四次变化率加权得到新状态。
    4. 更新时钟，再由新状态计算能量、记录角度。

  6. 从哪里开始，怎样算一步

    默认偏离直立15°、角速度0；RK4，Δt=1/240。wrapAngle 取角误差，角度的周期性与实体空间边界分别处理。

    默认15°偏角，第一瞬间会向哪边加速？

    取m=l=1、ω=0、控制开启。这里算变化率，帮助理解程序的第一步，不用Euler替代实际RK4。

    1. θ=15π/180≈0.26180 rad；位置反馈−30θ≈−7.85398 N·m，没有超过15。
    2. 重力力矩9.81 sinθ≈2.53901，阻尼为0。
    3. ω̇≈2.53901−7.85398=−5.31497 rad/s²；加速度朝直立方向，θ̇此刻仍为0。

  7. 怎样核验 · 参考资料

    下面是可以自己做的核验及预期，不表示所有现实用途都已经被验证。

    • 关闭控制和阻尼，检查总能量

      应看到：E=Iω²/2+mgl cosθ应近似恒定；减小时间步后漂移应减小。

    • 把Kp降到mgl以下，保留正Kd

      应看到：直立附近出现负有效刚度；增大阻尼不能消掉不稳定的增长方向。

    先预测，再只改一个条件

    若 Kp<mgl，即使 Kd 很大还能局部稳定直立吗？

    理想平面质点摆；局部极点结论不能保证大角度、力矩饱和时都能回到直立。

HOW IT WORKS

把非线性运动和线性稳定性放在一起看

01 · 用什么机械模型？

I = ml²
I θ̈ = mgl sin θ − b θ̇ + τ
τ = sat(−Kp θwrap − Kd θ̇, ±τmax)

杆无质量，末端是集中质量 m，支点固定、无摩擦以外的约束。l 是支点到质点的距离，b 为关节黏性阻尼，g = 9.81 m/s²。τ 是关节电机直接施加的力矩。θ = 0 是竖直向上，因此重力项是正号，会把直立的小偏差越推越大。

这是直接驱动关节的单摆／倒立摆，不是通过小车横移平衡的欠驱动小车摆。控制器使用折回到 [−π,π] 的角误差，避免多转一圈后要求返回同一个绝对圈数；折回边界处并不光滑。

02 · 为什么反馈能扶正？

直立附近 θ 很小、控制未饱和时 sin θ ≈ θ，方程变为：

I θ̈ + (b + Kd) θ̇ + (Kp − mgl) θ = 0
I λ² + (b + Kd) λ + (Kp − mgl) = 0

I > 0 时，二阶系统渐近稳定需要 Kp > mgl 且 b + Kd > 0，并要求执行器确实能施加非零力矩。比例反馈要强过重力的“负刚度”，阻尼／微分反馈则消耗振荡。

质量或摆长增大，mgl 的门槛也增大；惯量 ml² 同时改变响应速度。上面的即时极点用当前参数计算，实部为负才表示小扰动衰减。

03 · 局部稳定不等于任何角度都能救回来

“力矩受限”预设拥有足够的形式增益，但电机最大只有 2 N·m，初始倾角很大，真实控制已饱和，不能指望小角度极点描述整个过程。这里没有 swing-up 控制器、能量整形或最优控制。

“无控制倒下”从 5° 开始；完全精确的 0°、0 角速度会在理想数学模型中保持直立，但它是不稳定平衡。自然下垂在有阻尼时稳定；无阻尼下的小幅下垂振荡不会自动消失。

换到相图，稳定直立通常表现为轨迹向原点收缩；无控制轨迹离开直立，最后可能到下垂。因为角度是圆周变量，图的左右边缘实际相接。

04 · 电脑怎样求解？

z = (θ, ω)
ż = (ω, [mgl sin θ − bω + τ]/ml²)

本页对这个完整非线性常微分方程使用固定 Δt = 1/240 s 的四阶 Runge–Kutta，每个子阶段重新计算反馈与饱和；动画帧率不决定积分步长。播放倍率只决定每秒算多少小步。

可先比较“反馈扶正”和“反馈不够强”，再增加质量或长度，观察极点和运动如何一起改变。最后点“推一下”，区分初始条件、外部扰动和模型参数的作用。

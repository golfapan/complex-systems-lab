二维流体 · 看见看不见的流动

反向旋转的涡能一起前进，同向旋转的涡能彼此绕行。加入两种染料，看看流动怎样拉伸、卷曲和混合。

从一个有趣的问题开始

咖啡里的奶，为什么会拉成长丝？

往咖啡里加一点奶，再轻轻搅一下，颜色不会马上均匀，而是先绕成弧线、拉成长丝。水流在搬运颜色，颜色反过来让我们看见原本透明的流动。这里把杯子换成一个简化的二维世界：放进两团染料与几种涡流，看看旋转方向和黏性怎样改变它们相遇的方式。

先猜一猜：两只反向旋转的涡，会互相抵消，还是一起向前走？先观察预设，再拖动画面搅动。

演化中…

按住画面拖动，会加入染料和局部涡量；暂停时也能编辑。粉／蓝染料只是示踪剂，不是两种不同流体；涡量视图中粉色为正、蓝色为负。

四个流动起点

黏性大，涡更快衰减；黏性设为零仍有插值带来的数值扩散。改参数会暂停并保留当前流场，点继续或重播。预设保留黏性和播放倍率。

同向双涡在周期区域内自动减去平均涡量，等效含一个均匀的反向涡量背景；不是无限空间中完全孤立的两个涡。

  1. 从现象开始：为什么这样建模

    涡流怎样搬运并混合染料？

    二维周期不可压缩流体与被动染料；没有墙壁、入口出口或染料反过来驱动流体。

    把水看成连续介质，不追踪每个分子。先用质量守恒要求流动不凭空压缩或膨胀，再用牛顿第二定律平衡惯性、压力和黏性。这得到不可压 Navier–Stokes 方程；红、蓝颜色只是被水携带的染料，不是两种会互相推动的流体。

    在二维中，可以改用“局部转得有多强”的涡量ω来记流动。对动量方程取旋度，压力梯度消去，留下涡量的搬运与黏性扩散。再由ω重建速度，速度又负责搬运ω，反馈因此闭合。

    “状态”是此刻必须记住、才能继续算的量；“输入”从外部给定；“参数”在一次运行中固定；“输出／辅助量”由已有状态算出。下面按这个实验分别对应。

  3. 一步、一格和随机数分别是什么

    一步代表什么：物理方程使用连续时间；浏览器每次用Δt=0.2近似向前推进。播放更快只是每帧多算几次，不是把物理黏度改变。

    空间怎样表示：计算区域为128×128格，格距按1计。左右、上下周期相接，相当于没有墙的平面环面。未标定米和秒，不应把一格直接理解为一厘米。

    随机数在哪里出现：默认涡对、剪切等起点由确定公式生成；演化不逐步抽随机数。鼠标搅动是外部输入，不是随机力。

  4. 从原理和关系推到方程

    1. 先写水的收支

      密度近似常数时，流入与流出体积相等，得到∇·(u,v)=0。黏性假设为牛顿流体，内部摩擦贡献ν∇²速度；惯性既包括本处速度随时间改变，也包括流体移到另一处时遇到不同速度。

    2. 用旋度去掉压力

      定义ω=∂ₓv−∂ᵧu。对二维无体力动量方程取旋度，得到式（2）；ω仍被自己产生的速度搬运，因此并不是独立的热扩散。

    3. 把涡量接回速度

      选u=∂ᵧψ、v=−∂ₓψ，质量守恒自动满足；代回ω的定义得到−∇²ψ=ω。本站用快速傅里叶变换FFT解这个关系；周期区域的平均ω及平均背景速度取0。

    4. 让连续方程可以算

      先用旧速度向后追踪落点，从旧网格插值得到搬运后的ω和两色染料；再对ω做隐式黏性扩散并重建速度。染料没有另加分子扩散项，但插值本身会产生数值模糊。

  5. 编号方程：逐条读懂，再看计算顺序

    先把本模型要用的式子放在一起。括号编号只在本模型内使用；物理关系、规则定义与数值推进的区别在下面逐条说明。

    （1）
    ∇·u = 0；∂ₜu + (u·∇)u = −∇p/ρ + ν∇²u，u=(u,v)
    （2）
    ω = ∂ₓv − ∂ᵧu；∂ₜω + u∂ₓω + v∂ᵧω = ν∇²ω
    （3）
    −∇²ψ = ω；u = ∂ᵧψ；v = −∂ₓψ
    （4）
    ∂ₜc + u∂ₓc + v∂ᵧc = 0，c分别取cᵣ、cᵦ
    （5）
    x回溯 = x − Δt·uⁿ(x)；q̃(x) = 插值[qⁿ](x回溯)
    （6）
    ω̂ⁿ⁺¹(k) = ω̃̂(k)/(1 + νΔt|k|²)，k≠0；ω̂ⁿ⁺¹(0)=0

    每个式子在说什么？

    式（1）

    连续介质的起点。第一式是质量守恒；第二式左边是随流体走的加速度，右边分别为压力推动和黏性摩擦。此处没有外力；鼠标搅动通过直接修改初始/当前涡量实现。

    式（2）

    前半定义旋转强度，后半说明变化来源。u∂ₓω+v∂ᵧω叫平流：把已有的旋转带到别处；ν∇²ω把尖锐的旋转差异摊平。

    式（3）

    这是同一时刻的重建关系，不是又多出三套独立时间演化。知道整张ω图及周期边界，就可求ψ和速度。

    式（4）

    染料随水移动但不反过来改变水流。红蓝重叠只是浓度叠加显示，不代表发生化学反应。

    式（5）

    数值搬运式，q分别取ω和两种染料。上标n是旧时刻；从新格点沿旧速度倒着走，再读取旧值。二维用四个周围格点做双线性插值。

    式（6）

    这是数值扩散，不是额外物理定律。短波的|k|大，分母更大，衰减更强；随后用式（3）得到新速度。波数0的平均涡量被清零，以满足本页周期求解约定。 隐式的意思是扩散右端取新ω：由(ω新−ω搬运后)/Δt=ν∇²ω新，利用每个傅里叶波的∇²对应−|k|²，移项便得到这个分母。

    程序怎样把它们接成一步？

    1. 读取当前ω、速度及红蓝浓度；整步搬运都使用同一套旧速度。
    2. 按式（5）分别回溯、插值ω、红浓度、蓝浓度；每个场先写临时数组再整体替换。
    3. 把搬运后的ω变换到傅里叶域，按式（6）加入黏性衰减。
    4. 由新ω求ψ与新速度，回到空间网格；时间增加0.2，画出染料并计算平均动能。

  6. 从哪里开始，怎样算一步

    128×128 周期区域，指定涡对／剪切等初态；半拉格朗日回溯搬运，FFT 求流函数并作隐式黏性衰减，Δt=0.2。染料插值有数值耗散。

    先算一次搬运，再看黏性怎样起作用

    取一条水平线作局部示例，u=2、v=0、Δt=0.2；这只是为了手算，真实速度来自整张涡量图。

    1. 新格点x=10的回溯位置为10−0.2×2=9.6。
    2. 若旧染料c(9)=0.2、c(10)=0.6，线性插值给出c新(10)=0.4×0.2+0.6×0.6=0.44。没有在本处“制造”染料，而是读取上游。

HOW IT WORKS

这次是真正的偏微分方程

01 · 从速度，到涡量

∂u/∂t + (u · ∇)u = −∇p/ρ + ν∇²u
∇ · u = 0
ω = ∂v/∂x − ∂u/∂y

u = (u,v) 是二维速度向量，p 是压力，ν 是运动黏性。第一项是随时间变化，非线性项 (u · ∇)u 表示流动搬运自己的速度，黏性项使速度差异扩散。第二行是不可压缩条件。

区别于 Lenia 的标量活性场，这里的速度有 x、y 两个分量；但二维不可压缩条件允许我们改用一个标量涡量来求解。

02 · 本页实际计算的模型

∂ω/∂t + u ∂ω/∂x + v ∂ω/∂y = ν∇²ω
−∇²ψ = ω
u = ∂ψ/∂y，v = −∂ψ/∂x
∂c/∂t + u · ∇c = 0

ψ 是流函数；它的旋转梯度自动满足不可压缩条件。c 是各个被动染料的浓度，不改变流动。拖动属于额外加入涡量的外部输入，松开后没有持续驱动力。

模型为 128 × 128 周期区域，边缘相接，没有墙壁、自由水面或障碍物。每个格子的长度取 1，时间用模型单位，所以滑条 ν 的单位是“格长²／模型时间”，不能直接当成真实水的 SI 黏性。

03 · 数值方法和它的限制

  1. 搬运：从每格沿当前速度反向追踪一个 Δt = 0.2 的小步，双线性插值取回上游的涡量和染料。这是半拉格朗日平流。
  2. 黏性：在 Fourier 空间用 ω̂new = ω̂adv/(1 + νΔt|k|²) 做隐式扩散。
  3. 求速度：对非零频率求 ψ̂ = ω̂/|k|²，再用 Fourier 导数求 u、v；零频率涡量设为零，使周期 Poisson 方程可解。

使用 FFT 是求空间方程的方法，不是给动画额外添加波纹。这里没有三维涡伸长；半拉格朗日插值会抹平细节，也不严格守恒染料总量。数值稳定不等于精度足够，低黏性下的漂亮细丝不能当作已验证的真实湍流。

04 · 建议观察

  • 反向双涡：为什么不是原地旋转，而是整体前进？两个涡诱导的速度互相叠加。
  • 同向双涡：切到涡量与速度箭头，看相互绕行及黏性融合。
  • 染料混合：降低黏性，观察色块被拉长；再提高黏性，比较流动能持续多久。
  • 停止搅动后看平均动能如何变化。插值也会损耗能量；这个量是数值诊断，不是实测能量。

下一类可拓展的现象包括圆柱尾涡、浅水波、对流和 Rayleigh–Bénard 花纹，但需要加入各自的边界条件和物理变量，本页不把染料卷曲冒称为已经实现这些模型。

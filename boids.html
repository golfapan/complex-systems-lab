Boids · 一群鸟怎样一起飞？

没有领头鸟，每只鸟只看附近的伙伴。调节分离、对齐、聚拢，看整体秩序如何出现。

从一个有趣的问题开始

鸟群转弯时，谁在喊口令？

傍晚一群鸟突然转向，几乎像同一块会流动的布。可是每只鸟只看得见身边一小部分伙伴，未必知道整群要去哪里。假如你是一只鸟，只遵守三件小事：别撞上、跟邻居朝同一方向、别掉队，整群能自己组织起来吗？在这里没有领队，你可以逐条关掉规则，看看秩序怎样出现，又怎样消失。

先猜一猜：只有“别撞上”这一条，能不能让大家一起飞？先试只管避让，再加入对齐。

HOW IT WORKS

局部互动，怎样变成整体秩序？

01 · 三条规则

  • 分离：距离小于 26 个画布单位的邻居越近，越想避开；贡献方向正比于 −r/|r|²。
  • 对齐：让自己的朝向靠近感知范围内邻居的平均速度方向。
  • 聚拢：朝邻居相对位置的平均方向转向。跨边界时用周期空间的最短位移，避免错误地飞向画布中央。

本页使用二维、全方向感知和固定飞行速度，是 Reynolds 思想的教学变体，不是鸟类行为的实验拟合。

02 · 具体怎样计算？

aᵢ = limit(wₛ sᵢ + wₐ aᵢalign + w꜀ cᵢ, 220)
ṽᵢ = vᵢ + Δt aᵢ
vᵢnew = vspeed ṽᵢ / |ṽᵢ|
xᵢnew = wrap(xᵢ + Δt vᵢnew)

每条规则先把期望方向变成“期望速度 − 当前速度”，并将其加速度限在 120 以内；再按滑条权重相加，并把总加速度限为 220。Δt 固定为 1/60 s。所有鸟根据同一旧状态同时更新，避免先算的鸟影响后算的鸟。

这是一个带邻域切换、限幅和速度归一化的离散多智能体模型。可以提出连续时间的转向模型，但本页展示的具体规则并非严格微分方程的精确解。

03 · 可以研究什么？

“朝向一致度”是单位速度向量平均值的长度，范围 0～1。接近 1 表示大多数鸟朝向一致；接近 0 也可能是两群反向飞行，不等于完全无序。

  1. 先选“一起飞”，观察局部小群是否逐渐协调。
  2. 选“只管避让”，保留碰撞回避，去掉对齐和聚拢，比较整体方向。
  3. 把对齐从 0 慢慢增加，再扩大感知半径，观察秩序是否更容易形成。
  4. 强聚拢可能让鸟过度集中；分离与聚拢之间的竞争决定群的尺度。

速度较快、感知范围过小或离散步长太大时仍可能交叠；这不是严格的无碰撞控制器。没有真实空气动力、障碍物或训练过程。

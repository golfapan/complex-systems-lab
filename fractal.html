分形 · 局部里面，还有世界

Fractal（分形）：从 Mandelbrot 集的边界出发，反复放大，寻找似曾相识却又不同的螺旋、海马与小岛。

从一个有趣的问题开始

一张地图，为什么越放大越有东西？

普通照片放大到最后只剩像素。如果一幅图不是照片，而是每个位置都按同一条复数规则计算出来的呢？沿着 Mandelbrot 集的边界往里走，你会遇到像海马、螺旋和小岛的结构，局部似曾相识，却又不完全相同。这里不用找出全部数学证明，先做一次探索：挑一个位置，看看下一层藏着什么。

从这几个地方开始

改变 c 会保留当前 Julia 视野。参数支持 −8～8；若图案离开视野，重新选择“Julia 花园”。

放大时自动增加计算预算，实际最多 5000 次。提高上限能分辨慢逃逸的边界，也会更慢。
实际分辨率还受画布尺寸和屏幕像素比限制；放大后会重新计算，不是单纯拉大旧图片。

数学结构可以继续放大；本版使用双精度数值，限制到约 10¹⁰ 倍。接近边界时有限迭代也会产生误判，不能把黑色像素都当作严格证明的集合内部。

怎样建立这个模型？

从原理、变量和关系出发，读懂编号方程，再亲手算一步。 查看建模方法与常见关系 →

  1. 从现象开始：为什么这样建模

    复数反复平方后，有哪些初值不会逃向无穷？

    复平面上的抽象迭代；像素分别计算，视窗没有相互作用边界。

    先选一个极简单的复数映射：把当前复数平方，再加固定复数c。问题不是粒子受什么力，而是这个数学定义反复作用后，轨道会留在有限范围还是逃向无穷。

    一张图包含许多互不作用的轨道：Mandelbrot固定起点z₀=0、逐像素改变c；填充Julia固定c、逐像素改变起点z₀。两者画在同样的复平面上，却在扫描不同对象。

  2. 先认清每一个量

    “状态”是此刻必须记住、才能继续算的量；“输入”从外部给定；“参数”在一次运行中固定；“输出／辅助量”由已有状态算出。下面按这个实验分别对应。

    符号它表示什么在模型里做什么单位或范围
    zₙ=aₙ+ibₙ第n次迭代的复数，a和b为实/虚部轨道状态无量纲复数
    c=cᵣ+icᵢ每条轨道中固定的复数常量映射参数无量纲复数
    n、N已迭代次数与最大迭代预算；默认预算700计数、计算设置次
    |z|²=a²+b²复数到原点的距离平方逃逸检查量无量纲
    R安全逃逸半径；本站取max(2,|c|)数学判定阈值无量纲
    像素位置Mandelbrot中代表c，Julia中代表z₀采样坐标，不是相互作用网格复平面坐标
    i²=−1；cᵣ、cᵢi为虚数单位，cᵣ、cᵢ分别是c的实部、虚部；下标i在此不表示格点编号复数定义及分量无量纲
    对照本页默认值与可调参数

    c 决定 Julia 形状；最大迭代数是判定预算，视窗和像素数是采样设置。

  3. 一步、一格和随机数分别是什么

    一步代表什么：n只表示重复计算了几次，不预设物理秒数；加大预算是在问更久以后是否逃逸。

    空间怎样表示：复平面取一个矩形视窗，每个像素独立计算；放大是加密采样，图像左右边缘不连接。

    随机数在哪里出现：确定性映射无随机数；细碎图案不意味着底层有噪声。

  4. 从原理和关系推到方程

    1. 把复数平方拆成可计算的两条实数关系

      (a+ib)²=(a²−b²)+i(2ab)，再把c的实虚部分分别加进去。计算新b时必须仍用旧a，不能用刚算出的新a。

    2. 选择画的是参数还是起点

      Mandelbrot每条轨道均从0开始，改变参数c；Julia让所有像素共享同一个c，但各像素以自身坐标作z₀。

    3. 从增长不等式得到停止条件

      三角不等式给|z²+c|≥|z|²−|c|。一旦|z|>max(2,|c|)，后续模长会继续增长，安全判为逃逸；因此不必等到真的算出无穷。

    4. 把有限计算与数学集合分开

      预算内未逃逸通常涂深色，但它只是目前未判为逃逸。代码还用主心形/周期2圆盘的解析内点检查加速部分Mandelbrot像素。

  5. 编号方程：逐条读懂，再看计算顺序

    先把本模型要用的式子放在一起。括号编号只在本模型内使用；物理关系、规则定义与数值推进的区别在下面逐条说明。

    （1）
    zₙ₊₁ = zₙ² + c
    （2）
    aₙ₊₁ = aₙ² − bₙ² + cᵣ
    （3）
    bₙ₊₁ = 2aₙbₙ + cᵢ
    （4）
    R² = max(4, cᵣ²+cᵢ²)；aₙ²+bₙ²>R² ⇒ 逃逸
    （5）
    M：固定z₀=0，扫描c；Kc：固定c，扫描z₀；Jc=Kc的边界

    每个式子在说什么？

    式（1）

    完整映射定义；同一条轨道的c始终不变。

    式（2）

    实部的更新式，右边全来自第n次状态。

    式（3）

    虚部的更新式，与上一式同步计算。

    式（4）

    代码直接比较距离平方，省去开方。Mandelbrot经典半径2已够用，本站在|c|>2时使用更保守的同一安全式。

    式（5）

    Kc是填充Julia集合，Jc才是其边界；页面显示的有界区域近似不应与边界集合混称。

    程序怎样把它们接成一步？

    1. 按像素坐标确定本次的c或z₀。
    2. 保存旧a、b，依两条实数式同时算新值。
    3. 检查新模长平方是否超过R²；超过则记录逃逸次数并停止。
    4. 否则继续直到预算N；显示颜色表示逃逸快慢，预算内未逃逸保留为未逃逸/未判定。

  6. 从哪里开始，怎样算一步

    逐像素迭代，达到逃逸条件或预算即停止；复平面视窗是采样范围，边缘像素不会与另一侧相互作用。

    同一规则，为什么有的点逃逸、有的点循环？

    采用Mandelbrot模式，所有轨道z₀=0；分别选择实参数c=2和c=−1。

    1. c=2：z₁=2，恰在半径2上；z₂=2²+2=6，超过2；z₃=38，持续增大，第二步后已可停止。
    2. c=−1：z₁=−1，z₂=0，z₃=−1，之后在0与−1之间循环；它确实有界。
    3. Julia若选c=0，起点模长r每步变成r²；r<1收缩，r>1增长，r=1留在单位圆上。
    4. 因此c=0的填充Julia是单位圆盘，其边界是单位圆；这是一项可用解析结果核查图像的例子。

  7. 怎样核验 · 参考资料

    下面是可以自己做的核验及预期，不表示所有现实用途都已经被验证。

    • 使用c=0的Julia，并比较起点模长0.5与1.5。

      应看到：前者趋0，后者逃逸；图上单位圆盘应保持圆形，不能因像素映射被拉成椭圆。

    • 固定视窗，把最大迭代预算翻倍。

      应看到：已确定逃逸点仍逃逸；一些先前深色点可能后来逃逸，边界细节需要更高预算。

    把迭代预算加倍，原来深色的点会不会被判逃逸？

本模型的关系：变量相乘、反复迭代

HOW IT WORKS

只有一个公式，为什么能这么复杂？

01 / THE NAME

分形、自相似，以及“不完全相同”

“分形”是一类在细尺度上仍有复杂结构的几何对象。某些分形具有严格的缩放自相似，例如 Koch 雪花；Mandelbrot 集则出现许多近似相似、经过变形的局部图案和小复制体，不能说任意局部都与整体完全相同。

曼德勃罗集的边界在反复放大后仍会展现丰富细节。内部的黑色轮廓和外部的彩色条带，来自不同像素的迭代结果。

02 / ONE RECURRENCE

先理解这个复数迭代

zₙ₊₁ = zₙ² + c
zₙ = xₙ + i yₙ，c = a + ib
xₙ₊₁ = xₙ² − yₙ² + a
yₙ₊₁ = 2xₙyₙ + b

复数乘法可以拆成下面两条实数更新式。每一轮都要使用同一旧时刻的 xₙ、yₙ，不能先更新 x 再拿新 x 算 y。

它是离散非线性动力系统。n 是迭代轮数，没有 x、y 方向的空间导数，也不是一条偏微分方程的时间离散结果。复杂形状来自反复平方的非线性。

03 / TWO DIFFERENT PLANES

Mandelbrot 和 Julia，看的是不同的问题

Mandelbrot：固定初值 z₀ = 0，画面每个像素给出不同的 c。反复迭代后，如果轨道始终有界，这个 c 属于 Mandelbrot 集。因此整张图是一个参数地图。

填充 Julia：固定 c，画面每个像素给出不同的初值 z₀。图中候选黑色区域表示轨道未在预算内逃逸的初值；它的真正集合边界才是通常所说的 Julia 集。

点“从 Mandelbrot 选点看 Julia”，再选一个 c，就能理解这两个世界的对应关系。选到 Mandelbrot 外的 c 时，填充 Julia 集也可能成为很多不连通的小碎片。

04 / ESCAPE TIME

每个像素怎样得到颜色？

  1. 把像素坐标变成复平面坐标。
  2. 按选定模式确定 c 和初值。
  3. 重复迭代，直到逃逸或达到预算。
  4. 按逃逸快慢着色；未判定逃逸的像素画为深色。

Mandelbrot 中从 0 出发，一旦 |z| > 2 就能判定逃向无穷。本页统一使用更保守的逃逸半径 max(2, |c|)，也适用于这里可调参数的 Julia 模式；对不在 Mandelbrot 中的大 c，可能多算一小步。

ν = n + 1 − log₂(log |zₙ|)

外部颜色使用平滑逃逸计数 ν，再映射到周期色带，减少整数迭代造成的硬边。配色是显示选择，不会改变集合。主心形和周期二圆盘有解析内部判定，其余未逃逸点只是有限预算内的候选。

05 / INSTABILITY

分形与动力系统稳定性有什么关系？

δzₙ₊₁ ≈ 2zₙ δzₙ + δc

这是对原迭代的小扰动线性化：很小的初值或参数差异，会在每轮受到 2zₙ 的影响。在某些轨道上扰动被放大，另一些轨道则会被吸引到稳定周期附近。许多不同结局之间的复杂边界产生了丰富几何。

因此它与稳定性、分岔和混沌有关，但“有分形图案”并不自动等于每一条轨道都是混沌。例如 c = 0 时，z₀ = 0 会永远停在 0；c = −1 时，从 0 开始就在 0 与 −1 之间循环。

流体等 PDE 的解也可能产生复杂尺度或分形相关结构，但这张图不需要先求 PDE。分形是几何特征，微分／差分方程是描述演化的方式，两者不是同一个分类。

06 / LIMITS & EXPERIMENTS

怎样看，最有意思？

  1. 先看全景，再点“海马谷”或“小曼德勃罗”，比较局部和整体的相似与差别。
  2. 选“螺旋放大之旅”，观察同一个位置逐层出现新细节；想停随时再点一次。
  3. 在同一个位置提高迭代上限，观察哪些原本深色的像素变成了外部颜色。
  4. 用选点功能进入 Julia 图，再小幅改变 c 的实部或虚部，比较结构变化。

计算采用分块任务，支持中途取消。理论上的无限细节并不意味着普通电脑能无限精确显示；超过本版上限，需要高精度算术、扰动法等专门的深度缩放算法，而不是继续放大像素。

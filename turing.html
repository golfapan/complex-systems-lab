  1. 从现象开始：为什么这样建模

    均匀介质中的微小差别，何时会长成有间距的花纹？

    二维薄层内部局部反应和扩散；先忽略组织生长、三维几何和流动。

    从一薄层介质开始：某处的活性一方面受本处反应改变，另一方面与附近位置交换。只有扩散通常会抹平差异；当局部激活与抑制反馈配上不同扩散速度时，某些空间扰动反而可能增长，形成有间距的花纹。

    本实验采用 FitzHugh–Nagumo 型三次反应的教学变体。扩散来自局部收支和梯度通量；三次反应式是选定的机制模型，不是从具体化学反应逐项标定出的定律。u、v 是相对活性，可以为负，不能当作非负的化学浓度。

  2. 先认清每一个量

    “状态”是此刻必须记住、才能继续算的量；“输入”从外部给定；“参数”在一次运行中固定；“输出／辅助量”由已有状态算出。下面按这个实验分别对应。

    符号它表示什么在模型里做什么单位或范围
    u(x,y,t)位置(x,y)的激活活性；图中主要显示它随时间变化的状态场无量纲
    v(x,y,t)同一位置的抑制活性随时间变化的状态场无量纲
    b、r偏置和抑制/激活扩散系数比；默认b=0、r=20一次实验固定的模型参数无量纲
    Dᵤ、DᵥDᵤ=0.16，Dᵥ=0.16r；表示各场摊平空间差别的快慢模型参数模型长度²/模型时间
    h、Δth=0.5是一格间距；Δt=0.01是每次数值推进长度计算设置模型长度、模型时间
    ∇²u、∇²v本处相对周围的凹凸程度；决定扩散流入还是流出由当前场计算的空间量活性/模型长度²
    对照本页默认值与可调参数

    Dᵤ=0.16，Dᵥ=0.16r；r 控制扩散比，b 控制偏置。它们是模型参数；网格距和时间步是计算设置。

  3. 一步、一格和随机数分别是什么

    一步代表什么：方程中的时间连续；计算机每次用Δt=0.01近似推进，而屏幕每秒画几帧只影响观看。

    空间怎样表示：56×56的周期区域被分成112×112格；左右、上下连接。h用于把邻格差转换为空间二阶导数。

    随机数在哪里出现：随机数只给初始均匀平衡加微扰；初态确定后，每一步按同一方程计算，没有持续加随机噪声。

  4. 从原理和关系推到方程

    1. 先把本处反馈写出来

      u项表示小激活的自增强，−u³限制大幅增长，−v表示抑制，+b表示偏置；0.1设置这一组反应的时间尺度。v受+u推动并经−0.8v自行回落，外面的0.2设置其响应尺度。

    2. 再加入来自邻近位置的收支

      对任一活性w，假设通量J=−D∇w，即从高处向低处流。局部收支∂ₜw=反应−∇·J便给出反应+D∇²w。u、v分别使用自己的D。

    3. 把空间连续关系变成可计算的邻格关系

      横向和纵向二阶差分相加，得到五点Laplacian：四邻之和减4倍本格，再除以h²。均匀场此项恰为0，凸起处为负。

    4. 最后把变化率变成新状态

      先用同一张旧网格算两个变化率，再乘Δt加到旧值。若在扫格过程中立即覆盖旧值，后面的格会读到“未来”，就改变了所讲的模型。

  5. 编号方程：逐条读懂，再看计算顺序

    先把本模型要用的式子放在一起。括号编号只在本模型内使用；物理关系、规则定义与数值推进的区别在下面逐条说明。

    （1）
    ∂ₜu = 0.1(u − u³ − v + b) + Dᵤ∇²u
    （2）
    ∂ₜv = 0.2(u − 0.8v) + Dᵥ∇²v
    （3）
    Lₕwᵢ = (w左 + w右 + w上 + w下 − 4wᵢ)/h²
    （4）
    uᵢ⁺ = uᵢ + Δt[0.1(uᵢ − uᵢ³ − vᵢ + b) + DᵤLₕuᵢ]
    （5）
    vᵢ⁺ = vᵢ + Δt[0.2(uᵢ − 0.8vᵢ) + DᵥLₕvᵢ]

    每个式子在说什么？

    式（1）

    左边是u每单位模型时间的变化率；右边第一组负责本处激活/饱和/抑制，第二项只负责与邻近位置交换。

    式（2）

    u驱动v增加，v自身回落；抑制场可以比激活场扩散得快，默认Dᵥ=3.2。

    式（3）

    w可替换为u或v；Lₕ是代码采用的空间二阶导数近似，而不是额外的反应。

    式（4）

    ⁺表示下一步；全部右端来自旧u、旧v。

    式（5）

    v也读取同一个旧时刻，完成后才一起切换到新网格。

    程序怎样把它们接成一步？

    1. 建立均匀反应平衡：v=u/0.8，且u³+0.25u−b=0；默认b=0时二者均为0。
    2. 叠加很小的初始扰动，并按周期边界找四邻。
    3. 逐格分别计算两组反应项和两组扩散项。
    4. 用上面两条更新式写入另外两张数组，再一起替换旧场。

  6. 从哪里开始，怎样算一步

    56×56 区域，112×112 网格，h=0.5，Δt=0.01；均匀平衡加微扰，双向周期边界，五点差分和同步 Euler。

    均匀场的一步：先隔离反应，再看扩散

    取全场u=0.1、v=0.2，使用b=0、h=0.5、Δt=0.01。因为各格相同，扩散应完全不出力。

    1. 四邻u之和=0.4，4u=0.4，所以Lₕu=0；v同理。
    2. u反应率=0.1(0.1−0.001−0.2)=−0.0101；新u=0.1−0.000101=0.099899。
    3. v反应率=0.2(0.1−0.16)=−0.012；新v=0.2−0.00012=0.19988。
    4. 若仅把某格u升高，四邻仍不变，该格的扩散项为负；同一扰动也会给邻格正贡献。

本模型的关系：浓度相乘 · 高的摊向低的

模型与数学

采用 FitzHugh–Nagumo 型激活—抑制模型。u 是激活场，v 是抑制场，均为可正可负的相对活性；深色表示 u 较高。

① 激活场：自己增强，也受到限制

∂u/∂t = 0.1(u − u³ − v + b) + Dᵤ∇²u
  • ∂u/∂t：这里的激活程度随时间变化得多快。
  • ＋u：在零附近提供局部正反馈，放大微小差异。
  • −u³：活性变大后限制振幅，避免正负两边无限放大。
  • −v：抑制场升高，会压低这里的 u。
  • ＋b：反应偏置，对应第一个滑杆；接近 0 时两类区域较平衡，偏离 0 更容易形成斑点或反色斑点。
  • Dᵤ∇²u：激活场向周围扩散。邻域平均比这里高就补进来，比这里低就向外流。

② 抑制场：被激活产生，逐渐衰减，也会传播

∂v/∂t = 0.2(u − 0.8v) + Dᵥ∇²v
  • ＋u：u 升高会推动 v 增加。
  • −0.8v：v 自身逐渐回落；连同外面的 0.2，实际衰减项是 −0.16v。
  • Dᵥ∇²v：抑制场扩散，本页始终比激活场快，能影响更远的区域。

把两式连起来：u 升高 → 推动 v 增加 → v 反过来压低 u。再加上两者传播范围不同，就可能留下有间距的花纹。

参数之间的对应关系

当前：b = 0.000；r = 20.0；Dᵤ = 0.16；Dᵥ = 3.20。

参数在本页的作用
b可调偏置 −0.12～0.12；影响两类区域的平衡和图案类型，不是“增强强度”。
Dᵤ = 0.16固定的激活场扩散系数。
r = Dᵥ/Dᵤ第二个滑杆实际调 r，范围 4～32；Dᵥ = 0.16r，显示的是同一时间下的扩散长度比 √r。
0.1、0.2固定的局部反应速率系数，不是扩散系数；不等于整个图案简单按两倍速度生长。
0.8固定的 v 衰减系数，和外面的 0.2 一起作用。
演化速度只改变每秒计算多少个小步，不改变这两条方程，也不放大数值步长。

四个预设为什么不同？

迷宫、平行与斜向条纹都用 b = 0、r = 20；后两者额外加入微弱的定向初始扰动。斑点预设用 b = 0.12、r = 20，只有随机扰动。因此方向不单由两个滑杆决定；这些是本页验证过的教学示例，不是动物实测参数。

计算区域为 56 × 56，划分为 112 × 112 个点，间距 0.5。区域大小影响可容纳的条纹数量，网格间距决定空间分辨率。

小扰动与空间模态

线性分析告诉我们：哪些小扰动开始增长。非线性告诉我们：长大后如何受限、竞争，形成什么结构。花纹不是单靠“非线性很复杂”就能解释，也不是看起来复杂就等于混沌。

1．二维不是把 u、v 分别当成 x、y

u = u(x, y, t)，v = v(x, y, t)
∇²u = ∂²u/∂x² + ∂²u/∂y²
∇²v = ∂²v/∂x² + ∂²v/∂y²

每个位置同时有一个 u 和一个 v，就像地图上的每个地点同时有温度和湿度。x、y 是位置坐标，u、v 是两个标量场；不是把 u 拆成水平和竖直分量。只有变量本身是速度那样的向量，才需要另外定义水平、竖直分量。

完整模型不仅要有两条方程，还要指定：区域大小、起始的 u/v 分布，以及边界怎样处理。本页区域为 56 × 56，初始状态为均匀工作点加微小扰动，左右相接、上下相接。

2．电脑具体怎样求解？上下左右，再向前一步

把平面切成 112 × 112 个网格，每格存 uᵢⱼ、vᵢⱼ 两个数，共 25,088 个状态。空间离散以后，PDE 变成一大组耦合的非线性 ODE，再做时间积分，而不是先找到一条漂亮的解析公式。

Lₕuᵢⱼ = (uᵢ₊₁,ⱼ + uᵢ₋₁,ⱼ + uᵢ,ⱼ₊₁ + uᵢ,ⱼ₋₁ − 4uᵢⱼ) / h²

这叫五点差分：中心和上下左右。邻域平均高于中心就有净流入，低于中心就有净流出。对 v 用同样的算法。

uᵢⱼⁿ⁺¹ = uᵢⱼⁿ + Δt [F(uᵢⱼⁿ, vᵢⱼⁿ) + DᵤLₕuᵢⱼⁿ]
vᵢⱼⁿ⁺¹ = vᵢⱼⁿ + Δt [G(uᵢⱼⁿ, vᵢⱼⁿ) + DᵥLₕvᵢⱼⁿ]

其中 F = 0.1(u − u³ − v + b)，G = 0.2(u − 0.8v)；n 是时间步编号，不是空间坐标。本页用显式 Euler 步进，h = 0.5、Δt = 0.01。

所有下一步值都使用同一份旧状态。先算到新数组，再整体交换，不能刚更新左边就拿它去更新右边。重复这个过程才成为动画；加速档位只是每秒多算几步。

步长不能随意放大。本页最强扩散时 DᵥΔt/h² = 0.2048，小于方格上纯扩散显式格式的 1/4 界限；这只是扩散部分的稳定性检查，不替代对完整非线性系统及网格、时间步长的收敛检查。

3．“小东西”是什么？可以是一点点活性，也可以是一种空间波

先找均匀工作点 (u₀, v₀)：每个位置相同，扩散项为零，且 F = G = 0。本模型满足：

v₀ = 1.25u₀，u₀³ + 0.25u₀ = b
u = u₀ + δu，v = v₀ + δv

δu、δv 就是微小偏差。随机噪声可以看成很多不同波长、方向的空间波叠加；水平、斜向的初始提示则偏重其中某些方向。

如果初始状态完全均匀、精确停在工作点上，理想方程不会凭空选出一个斑点。本页主动加入微小初始扰动来触发演化；之后没有持续加入随机驱动。实际实验中的微扰与计算中的舍入误差，也可能成为不稳定模态的种子。

空间形状：cos(kₓx + kᵧy)
波长 ℓ = 2π / √(kₓ² + kᵧ²)

kₓ、kᵧ 共同决定波的尺度和方向。图案的条带沿等相位线延伸，波矢方向与条带垂直。这里说的“模态”，不是单个像素，而是一种覆盖空间的扰动形状。

同一个小扰动，若落在会衰减的模态上，就慢慢消失；若包含会增长的模态，那部分就被放大。不是所有小误差都会导致完全不同的结果。

4．用控制系统的语言：每个空间模态都有自己的“极点”

在工作点附近线性化，先忽略高阶扰动。两种场的反应 Jacobian 为：

J = 0.1(1 − 3u₀²)−0.10.2−0.16

加入空间波后，令 q = kₓ² + kᵧ²，每个模态的两种振幅组成向量 a，其早期演化满足：

da/dt = A(q)a
A(q) = J − q · diag(Dᵤ, Dᵥ)
模态振幅 ∝ exp[λ(q)t]

λ(q) 是 A(q) 的特征值。实部负，扰动衰减；实部正，扰动增长；虚部对应振荡。可用特征值、极点和稳定性工具，分别分析不同空间波长的扰动。

若有特征值实部恰好为零，线性化往往不足以判定完整非线性系统的稳定性，需要继续检查高阶项与临界条件。

一个直接代入本页方程的例子

仅针对 b = 0、r = 20：工作点是 u₀ = v₀ = 0。不考虑空间变化时，J 的迹为 −0.06、行列式为 0.004，满足实二阶系统的稳定条件“迹 < 0 且行列式 > 0”；单看行列式不够。

但连续模型取 q = 0.1 时，A(q) 的最大特征值约为 ＋0.046，这个空间模态会增长。也就是说，均匀的小变化可以衰减，某些有空间起伏的小变化却会被放大——这是扩散驱动失稳的核心。

这个数值是上述方程的线性化计算，不是动物实测结果。周期边界只允许特定空间波数；程序还使用离散拉普拉斯，所以实际可用模态及增长率须按网格与区域计算，不能把任意 q 都当成画布上的精确模态。

5．非线性到底在哪一步变重要？

在线性近似里，一个不稳定模态会持续指数增长，它本身不会解释为什么花纹最后停在某个有限振幅。随着扰动长大，−u³ 的影响不能再忽略，它限制幅度，并使不同模态不再能独立叠加。

线性分析解释“最初谁长得快”；非线性演化决定“长大以后怎样相互影响”。最终可能出现有限振幅条纹、斑点、缺陷与多种稳定格局，也可能随参数发生振荡或其他行为。最终格局还受初始条件、边界、区域大小影响，不只由某一项决定。

“换一组随机扰动”改变的是初始空间谱；改 b 或 r 改变的是系统本身。前者可能主要改变条纹位置、方向和分叉，后者可能改变平衡点、可增长的波长或图案类型。靠近失稳或分岔边界时，较小的参数变化也可能带来明显变化。

6．线性、确定性、稳定与混沌，不是同一个分类
概念应当怎样理解
线性满足叠加原理，分析工具较系统。线性系统同样能出现多模态振荡、共振、暂态放大，以及极点或时延引起的失稳，不能说“线性就不复杂”。
确定性在模型解唯一的前提下，给定同样初始、边界条件与参数，就有相应的确定演化。线性和非线性都可以是确定性的；加入随机驱动则是另一层选择。
非线性不再普遍满足叠加，可能有幅度相关响应、多稳态、分岔、极限环等。非线性不等于随机，也不保证出现混沌。
混沌某些确定性非线性系统中出现的长期非周期行为与敏感依赖等性质。不同起点落入不同的稳定花纹，不足以证明混沌；计算误差导致的杂乱也不是混沌证据。

线性控制方法可用于非线性系统在工作点附近的局部分析。从局部稳定性走到有限振幅和全局行为，才需要继续用非线性分析和数值实验。

7．可以怎样在这个页面上做对照？
  1. 固定 b、r，反复“从头重播”：同一初始扰动应给出同样的计算过程。
  2. 只点“换一组随机扰动”：比较位置和分叉，先不要改反应参数。
  3. 再只改 b 或 r：比较形态、间距和增长过程，区分“初始条件改变”和“方程参数改变”。
  4. 暂停后切换清晰／原始显示：图像对比会变，但计算状态不变。
  5. 演化速度只改观看时的推进率。判断模型是否可靠，还应另做网格和步长收敛检查，不能把播放快慢当成物理参数。

清晰度与“基本稳定”

速度档位决定每秒计算目标；改速度保留当前场。零档暂停，调回正数继续。

清晰模式使用固定高对比映射：把 u ∈ [−0.16, 0.16] 平滑映射到深浅两色，区间外饱和显示。原始模式使用 [−0.8, 0.8] 线性色标。二者均不自动放大初始噪声，也不改变计算场；连续场的柔和边缘不是单纯的像素问题。

至少演化 400 个无量纲时间单位后，连续 6 个时间窗口（每个约 8）内，两种场的最大逐点变化分别除以自身全场最大绝对值（至少取 1），均小于 0.5%，才标记为基本稳定。这不是永久稳定的数学证明，之后仍可能缓慢漂移。

动画最多演化到 t = 4000；快进单次最多推进 4000 或计算约 12 秒。尚未稳定会明确提示，可继续演化。

Langton’s Ant · 兰顿蚂蚁

转弯、改颜色、走一步。只有一只蚂蚁，却能留下复杂图案，甚至开始修一条“公路”。

从一个有趣的问题开始

一只迷路的蚂蚁，突然开始修公路

给一只机器蚂蚁一张空白方格纸。它看到一种颜色就右转，看到另一种就左转，翻转脚下颜色，再走一步。它既没有地图，也不知道目的地，前面留下的轨迹却越来越乱。更意外的是，经典规则跑久后，可能进入重复延伸的“公路”。原来环境里留下的痕迹，就能改变下一次选择。

先猜一猜：公路是蚂蚁学出来的，还是旧轨迹与固定规则共同造成的？对照空白起点和公路起点。

演化中…

米色是状态 0，其他颜色是状态 1、2……；粉色箭头表示蚂蚁当前位置与朝向。视野只是窗口，模型不在边缘回卷。

从简单到复杂

第一个字母对应米色格。R＝右转，L＝左转。输入规则后按“应用”，从空白世界重新开始。快到公路段预设是实际先计算 11000 步，不是画好的背景。

  1. 从现象开始：为什么这样建模

    只读脚下格色并转向，能走出怎样的路线？

    无限格面与一只蚂蚁；每步只读脚下一格，环境格色保留历史。

    与鸟群不同，这里只有一个主体，却会改写环境。蚂蚁每次只读脚下一格的颜色：按颜色转向、把颜色改掉、前进一步。它以后再次来到这里，读到的痕迹已经不同，因此路径可以复杂起来。

    这是确定性状态机，不是神经学习。蚂蚁的规则从头到尾不变，变化的是位置、朝向和格色记忆；要预测下一步，三者都必须保留。

  2. 先认清每一个量

    “状态”是此刻必须记住、才能继续算的量；“输入”从外部给定；“参数”在一次运行中固定；“输出／辅助量”由已有状态算出。下面按这个实验分别对应。

    符号它表示什么在模型里做什么单位或范围
    C(x,y)格点(x,y)的颜色编号；默认0白、1另一色环境状态/外部记忆整数
    (x,y)、d蚂蚁位置；d=0上、1右、2下、3左主体状态格、方向编号
    q颜色数，等于规则串长度；RL时q=2规则参数种
    turn(c)颜色c对应转向：R为+1，L为−1固定规则表四分之一圈
    e(d)朝向的单位位移；上=(0,−1)、右=(1,0)等位置更新的几何定义格/步
    n完成了多少次读色转向移动演化计数步
    对照本页默认值与可调参数

    默认规则串 RL；规则串长度决定颜色数，字母决定各色时向右或向左转。

  3. 一步、一格和随机数分别是什么

    一步代表什么：一“步”包含读色、转向、改色和移动四个动作；没有指定其对应多少秒。

    空间怎样表示：逻辑上是无限整数格面，稀疏字典只存非零颜色；屏幕边缘只是观察窗口，不是墙或周期边界。

    随机数在哪里出现：默认全白、规则RL、从原点朝上开始，完全不抽随机数；同一完整初态必得同一路径。

  4. 从原理和关系推到方程

    1. 用四方向编码转向

      朝向加1即顺时针转90°，减1即逆时针转90°；取mod4使3再右转回0，0左转回3。

    2. 让旧颜色决定行为

      当前格旧颜色c先查规则串第c个字母。查完才将颜色加1并按q循环；若先改色再查，蚂蚁会执行另一条规则。

    3. 用新朝向更新位置

      先转好再前进一格；当前位置和离开的格色同时成为下一步需要的状态。q=2时“颜色循环加一”正是翻黑白。

  5. 编号方程：逐条读懂，再看计算顺序

    先把本模型要用的式子放在一起。括号编号只在本模型内使用；物理关系、规则定义与数值推进的区别在下面逐条说明。

    （1）
    c = C(x,y)；d⁺ = (d + turn(c)) mod 4
    （2）
    C⁺(x,y) = (c+1) mod q；其他格色不变
    （3）
    (x⁺,y⁺) = (x,y) + e(d⁺)
    （4）
    e(0)=(0,−1)，e(1)=(1,0)，e(2)=(0,1)，e(3)=(−1,0)

    每个式子在说什么？

    式（1）

    读的是脚下旧色；RL意味着0色右转、1色左转，颜色名字互换可形成镜像约定。

    式（2）

    只改离开的这一格。这个可写环境承担记忆，不是权重训练。

    式（3）

    采用转完后的朝向前进一格；y向下增加，与网页画布一致。

    式（4）

    四个方向把朝向编号翻译成实际位移，是计算位置所必需的坐标约定。

    程序怎样把它们接成一步？

    1. 读脚下颜色c，同时保留旧朝向。
    2. 按规则串中c对应的字母转90°。
    3. 将离开的格色循环加一。
    4. 沿新方向走一格，步数加1；窗口移动不改变格面状态。

  6. 从哪里开始，怎样算一步

    全白初态、一只蚂蚁；稀疏字典表示逻辑无限格面，画布仅显示窗口，每步按读色→转向→改色→移动执行。

    默认RL：前五步怎样留下记忆？

    起点(0,0)，朝上d=0；全白意味着所有格C=0，遇0向右、遇1向左。

    1. 第1步：原点为0，右转朝右，把原点改1，走到(1,0)。
    2. 第2步：新格仍为0，右转朝下，改色后走到(1,1)。
    3. 第3、4步都遇0，分别朝左到(0,1)，再朝上回到(0,0)。
    4. 第5步再到原点时读到1，不再重复第1步；改为左转朝左，把原点变回0，走到(−1,0)。

  7. 怎样核验 · 参考资料

    下面是可以自己做的核验及预期，不表示所有现实用途都已经被验证。

    • 手动复算前五步，逐一核对位置、朝向和离开格颜色。

      应看到：应得到上面路径；只看位置会漏掉为何第5步改变方向。

    • 将完整初态平移十格，再使用相同规则。

      应看到：路径应整体平移，而形状不变；若只移动蚂蚁而不移动已有格色，这不是同一初态的平移。

    先预测，再只改一个条件

    只记蚂蚁位置而丢掉格色，能否唯一算出下一步？

    全白初态出现“公路”是规则与环境共同演化的结果，不是蚂蚁学会了走路，也不代表任意初态都会在相同时间出现同一路径。

本模型的关系：达到条件才行动

HOW IT WORKS

确定的规则，也能产生难预测的轨迹

01 · 标准两色 RL

  1. 在状态 0（米色）上：右转 90°。
  2. 在状态 1（绿色）上：左转 90°。
  3. 把脚下格子的状态加 1，再对状态数取模。
  4. 向新方向前进一步。

经典 RL 就是白格右转、黑格左转，并翻转脚下颜色。朝向最初为上；本页 y 坐标向下增加。一步一步完全确定，不使用随机数。

02 · 这是离散状态机，不是微分方程

c = Cₙ(xₙ, yₙ)
dₙ₊₁ = (dₙ + turn(c)) mod 4
Cₙ₊₁(xₙ, yₙ) = (c + 1) mod q
(xₙ₊₁, yₙ₊₁) = (xₙ, yₙ) + e(dₙ₊₁)

C 是格子状态，q 是规则字符串长度。除脚下格子外，其余格子不变。R 的 turn = +1，L 的 turn = −1；朝向顺序为上、右、下、左。全局状态还必须包括整个格子图案，不能只记蚂蚁的坐标和朝向。

它可以写成离散映射 Sₙ₊₁ = F(Sₙ)，但没有天然可缩小的时间步，也没有将 R/L 简单替换成微分的唯一方法。

03 · “公路”是什么？

从全空白出发的经典 RL，在初期复杂运动后会出现一个以 104 步为重复节奏、整体斜向平移的局部结构。整幅世界并不每 104 步回到原状，因为后面留下的道路还在延长。

点击“快到公路段”，再跟随蚂蚁观察局部；也可以暂停后连续快进。四态规则每次仍只转 90°，但同一个格子要经过四种颜色，能形成不同的几何组织。并不是任何规则、任何初始条件都必然走向同一种公路。

本页用坐标映射保存无限格子中的非零状态，视野不会改变模型；为控制浏览器开销，一次演化最多 100 万步，可重新开始。这是程序限制，不是数学定理。

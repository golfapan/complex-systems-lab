Langton’s Ant · 兰顿蚂蚁

转弯、改颜色、走一步。只有一只蚂蚁，却能留下复杂图案，甚至开始修一条“公路”。

从一个有趣的问题开始

一只迷路的蚂蚁，突然开始修公路

给一只机器蚂蚁一张空白方格纸。它看到一种颜色就右转，看到另一种就左转，翻转脚下颜色，再走一步。它既没有地图，也不知道目的地，前面留下的轨迹却越来越乱。更意外的是，经典规则跑久后，可能进入重复延伸的“公路”。原来环境里留下的痕迹，就能改变下一次选择。

先猜一猜：公路是蚂蚁学出来的，还是旧轨迹与固定规则共同造成的？对照空白起点和公路起点。

演化中…

米色是状态 0，其他颜色是状态 1、2……；粉色箭头表示蚂蚁当前位置与朝向。视野只是窗口，模型不在边缘回卷。

从简单到复杂

第一个字母对应米色格。R＝右转，L＝左转。输入规则后按“应用”，从空白世界重新开始。快到公路段预设是实际先计算 11000 步，不是画好的背景。

HOW IT WORKS

确定的规则，也能产生难预测的轨迹

01 · 标准两色 RL

  1. 在状态 0（米色）上：右转 90°。
  2. 在状态 1（绿色）上：左转 90°。
  3. 把脚下格子的状态加 1，再对状态数取模。
  4. 向新方向前进一步。

经典 RL 就是白格右转、黑格左转，并翻转脚下颜色。朝向最初为上；本页 y 坐标向下增加。一步一步完全确定，不使用随机数。

02 · 这是离散状态机，不是微分方程

c = Cₙ(xₙ, yₙ)
dₙ₊₁ = (dₙ + turn(c)) mod 4
Cₙ₊₁(xₙ, yₙ) = (c + 1) mod q
(xₙ₊₁, yₙ₊₁) = (xₙ, yₙ) + e(dₙ₊₁)

C 是格子状态，q 是规则字符串长度。除脚下格子外，其余格子不变。R 的 turn = +1，L 的 turn = −1；朝向顺序为上、右、下、左。全局状态还必须包括整个格子图案，不能只记蚂蚁的坐标和朝向。

它可以写成离散映射 Sₙ₊₁ = F(Sₙ)，但没有天然可缩小的时间步，也没有将 R/L 简单替换成微分的唯一方法。

03 · “公路”是什么？

从全空白出发的经典 RL，在初期复杂运动后会出现一个以 104 步为重复节奏、整体斜向平移的局部结构。整幅世界并不每 104 步回到原状，因为后面留下的道路还在延长。

点击“快到公路段”，再跟随蚂蚁观察局部；也可以暂停后连续快进。四态规则每次仍只转 90°，但同一个格子要经过四种颜色，能形成不同的几何组织。并不是任何规则、任何初始条件都必然走向同一种公路。

本页用坐标映射保存无限格子中的非零状态，视野不会改变模型；为控制浏览器开销，一次演化最多 100 万步，可重新开始。这是程序限制，不是数学定理。
